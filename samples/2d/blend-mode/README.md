# BlendMode 混合模式对照

用于人工检查新渲染引擎的混合结果、透明度、分组隔离，以及混合模式切换后的渲染状态恢复。覆盖 `hx.display.BlendMode` 中全部 15 种模式，无需下载资源。

入口为 `Main extends hx.core.HxmakerApplication`，通过 `init(GameStage, 1200, 960)` 初始化业务舞台。项目显式引用本仓库 `../../../src`，渲染后端使用本地配置的 `hxmaker-openfl`。

## 运行

确认本地配置了 `hxmaker-openfl`、OpenFL 及其依赖后，在本目录运行：

```bash
haxelib run openfl test project.xml html5
```

此命令会编译并启动示例，由你手动执行。样例尚未编译、运行或进行浏览器验收。

## 普通混合模式

上方 12 格每格依次显示 Quad、Image 和公式参考。实绘两列使用相同源色、尺寸、对象透明度及三色不透明背景，结果应一致。参考列在 CPU 上计算颜色，再通过普通 NORMAL 色块绘制，不使用待验证的混合模式，也不通过截图或离屏绘制生成参考。

覆盖 NORMAL、ADD、MULTIPLY、SCREEN、DIFFERENCE、SUBTRACT、SUBTRACT_FAST、INVERT、DARKEN、LIGHTEN、HARDLIGHT 和 OVERLAY。

- 点击“切换透明度”：依次为 `1 → 0.5 → 0.25 → 0 → 1`。透明度为零时，所有实绘源色块应消失，背景保持不变。
- 点击“切换源颜色”：粉色与绿色互换，两个颜色都包含高于及低于 0.5 的通道，便于区分 HARDLIGHT 与 OVERLAY。
- 点击“全部 NORMAL / 恢复”：直接修改同一批对象的 `blendMode`，格子标题保留原模式。强制 NORMAL 时普通格子的实绘结果应相同；恢复后重新出现各自的混合效果。SUBTRACT_FAST 格不显示参考列。
- 点击“重置”：恢复粉色、透明度 1 和各格原始模式。

参考公式针对不透明背景，令 `B` 为背景通道、`S` 为源通道、`a` 为源透明度，通道归一化到 `[0,1]`。除 ADD 外，输出为 `B × (1-a) + F(B,S) × a`。

| 模式 | F(B,S) 或最终输出 |
| --- | --- |
| NORMAL | S |
| ADD | 最终输出为 min(1, B + S × a) |
| MULTIPLY | B × S |
| SCREEN | 1 − (1−B) × (1−S) |
| DIFFERENCE | abs(B−S) |
| SUBTRACT | max(0, B−S) |
| INVERT | 1−B |
| DARKEN / LIGHTEN | min(B,S) / max(B,S) |
| HARDLIGHT | S ≤ 0.5 时为 2BS，否则为 1−2(1−B)(1−S) |
| OVERLAY | B ≤ 0.5 时为 2BS，否则为 1−2(1−B)(1−S) |

这些公式给出本样例的对照语义，不是对当前后端结果的认可。SUBTRACT_FAST 是引擎定义的特殊近似算法，文档说明其背景固定为 `vec4(0.5)`，因此不套用 SUBTRACT 的参考公式；需按后端约定单独判断。检查色块内部，边缘可能有纹理取样或像素对齐差异；8 位取整可能产生约一个色阶的差异。

## LAYER、ALPHA 与 ERASE

中下方三组使用固定参数，左侧为实际渲染，右侧为 CPU 生成的不透明参考图。

1. **LAYER + 父级 alpha=0.5**：先在组内叠放不透明红、蓝矩形，再对整个组应用 0.5 透明度。重叠区域只应用一次组透明度；不应出现把每个子对象分别设成半透明后的红蓝混色。
2. **LAYER → ALPHA**：橙蓝底图与遮罩 Image 同属于一个 `blendMode=LAYER` 的父容器。遮罩使用透明边框和 `0、85、170、255` 四档纹理 alpha，图案从左到右逐渐保留；透明边框应露出组外棋盘。
3. **LAYER → ERASE**：结构相同，图案从左到右逐渐擦除；遮罩透明边框不擦除底图。擦除只影响本组内容，不能擦掉棋盘或相邻格子。

遮罩的透明度来自纹理像素，上方透明度来自对象属性，分别覆盖这两个入口。所有纹理均通过 OpenFL CPU 像素创建，再包装为 hxmaker BitmapData；这部分是当前 OpenFL 示例的后端适配点。

## 状态恢复

底部按 `NORMAL → ADD → NORMAL → MULTIPLY → NORMAL → SCREEN → NORMAL` 的顺序提交对象，每项左边实绘、右边为相同输入的公式参考。

穿插的 NORMAL 项应始终相同，且不受前一项影响。结合顶部模式与透明度按钮来回切换，观察滤镜、普通合批及 Image 绘制之间是否有状态残留。文字、按钮和参考图也应保持颜色正常。

本样例用于目视验收，不执行 GPU 像素读回或自动判定，不代表完整的半透明目标缓冲、色彩空间或所有滤镜组合验收。

## 操作与验收

- 左键拖动转镜头，滚轮缩放；轻点可见地面指定目标，沿用此前轻点／拖动语义。
- WASD／方向键按世界 X/Z 移动，键盘操作会取消地面目标。空格或“起跳”按钮起跳。点击三维视口可重新取得键盘焦点，失焦清除按键。
- **直线撞墙**：角色应停在中央红墙前，不穿墙；按实际位移切换动画，停止后回到 Idle。
- **斜向滑动**：角色撞墙后沿墙移动，到达墙尾可继续接近目标。没有导航，不会自行规划绕墙路线。
- **高处落地**：从 Y=7 下落，检查脚底高度、grounded 与垂直速度；地面高度为零，接触可保留很小的 skinWidth 间隙。
- **单次扫掠 20 米**：从 X=4 向黄色薄墙直接请求 +X 20 米，应停在约 X=5.623，而不是穿到另一侧。日志 HXMAKER_COLLISION_SWEEP 记录位置，未自动宣称测试通过。
- **初始重叠**：传送进入中央墙内，下一次更新应推出，或在无法解除时明确报告 stuck。
- **封闭墙角**：向两堵红墙的夹角运动，应停止在墙角，不能穿过角落。
- **穿越蓝色层 2**：默认 mask=3 会被蓝墙阻挡；切到“仅 1”后重新点击该测试按钮，应穿过蓝墙，仍受红墙与地面阻挡。
- 低顶板位于 X=-5、Z=7 附近，使用键盘走入后起跳，检查顶板阻挡与重新落地。
- **销毁并重新进入场景**：检查资源重新加载、输入解绑及旧场景不继续更新。退出日志 HXMAKER_COLLISION_RELEASE 中世界应已销毁、注册数为零。

模型按 0.6 缩放，胶囊半径 0.35、总高度 1.9，脚底与节点世界位置对应。胶囊是主体的近似代理，摆动手臂不单独参与碰撞。场景只有显式箱体静态代理；不包含网格／坡面／台阶／动态刚体或角色互撞。

# 路径绘图与回归示例

该示例展示 `Graphics` 新的路径绘图能力。应用启动类为 `Main extends hx.core.HxmakerApplication`，业务舞台为 `GameStage extends hx.display.Stage`。

新增路径与数据类型位于 `hx.display.graphics` 包。详细接口说明见仓库中的 `docs/Graphics路径绘图说明.md`。

## 运行

先确保本地已配置 `hxmaker`、`hxmaker-openfl`、OpenFL 及相关依赖。项目显式加入本仓库的 `src` 源码路径。

在本目录运行：

```bash
haxelib run openfl test project.xml html5
```

上述命令会编译并启动示例，应由你确认后执行。本次代码修改期间没有运行它。

## 视觉检查

1. 左上应显示心形贝塞尔轮廓、凹五角星和圆弧扇形，填充不应跨越凹槽。
2. 右上对照三种端点和三种转角；半透明描边的普通转角应保持均匀，没有明显的深色重叠补片。
3. 中间矩形使用蓝色填充，圆形和折线使用黄色描边；设置填充颜色不应覆盖描边颜色。不同透明度和颜色变换应生效。
4. 左下按住鼠标或触摸拖动，观察连续手绘和圆头圆角，移出区域会结束当前笔画。
5. 点击“清空手绘”，图形应立即消失。
6. 点击“静止画面重绘”，中间靠右的小矩形应在粉色和绿色间切换；回调仅修改图形，不通过移动对象或更新文字触发刷新。

## 回归检查

点击“运行回归检查”，右下区域及控制台显示每项结果。检查覆盖：

- 整体边界、未使用顶点、舞台刷新与父容器布局通知。
- 清空后的画笔位置与线宽、填充和描边状态隔离。
- 折线和圆形描边的透明度与颜色参数传递。
- 凹多边形正反绕向的面积和凹槽覆盖。
- 二次、三次曲线、整圆、共线折返曲线。
- 普通转角的三角形面积、旧接口连续折线、端点范围和斜接限制。
- 路径及样式修改后的提交快照。
- 空路径、重复点、零半径、无效数组、非法索引与数值。
- 自交和孔洞拒绝时不会留下部分绘图命令。
- 低层借用顶点在修改后通过 `invalidate()` 刷新边界。

如果希望启动时自动执行这些检查，可以手动使用编译开关：

```bash
haxelib run openfl test project.xml html5 -Dgraphics_checks
```

检查代码位于 `Source/GraphicsChecks.hx`，不依赖测试框架。默认启动不自动执行回归检查。示例已添加，但尚未编译或运行，因此没有“已通过”的执行结果。

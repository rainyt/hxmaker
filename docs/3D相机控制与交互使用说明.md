## 范围与架构

新增能力都位于 hxmaker 核心层：环绕与跟随控制器、视口输入适配、世界射线查询和地面求交。不修改 hxmaker-openfl 的三维接口、GL 状态保护、多纹理渲染或帧调度。

控制器只接收指令并由业务 `update(dt)` 驱动；输入适配只监听 hxmaker 的 Scene3D 和 Stage。业务示例使用 `HxmakerApplication → Stage → Scene` 结构，通过 Assets 加载 GLB，不直接访问 OpenFL、Lime、原生输入或浏览器。

本阶段交付独立的 [camera-interaction 示例](../samples/3d/camera-interaction/README.md)。其中的地面移动用于连接相机、拾取与动画，不提供碰撞、导航或重力。后续 Procedure 整合已加入[完整角色项目示例](完整3D角色项目示例说明.md)，该新增阶段单独等待用户测试。

## 环绕相机

```haxe
var orbit = new hx.controls3d.OrbitCameraController3D(camera, new hx.geom.Vector3D(0,1.5,0));
orbit.distance = 10;
orbit.yaw = 15;
orbit.pitch = 25;
orbit.minDistance = 1;
orbit.maxDistance = 30;
orbit.minPitch = 5;
orbit.maxPitch = 80;
orbit.snap();
```

`target` 是世界坐标观察点，yaw/pitch 单位是度，distance 是世界距离。yaw 为零时相机位于观察点的 +Z 方向；正俯仰使相机升高。构造时复制输入目标向量，不修改调用方的向量。

| 接口 | 作用 |
| --- | --- |
| `rotate(deltaYaw, deltaPitch)` | 增量改变角度，俯仰限制在配置范围 |
| `zoomBy(factor)` | 大于 1 拉远，小于 1 拉近，距离限制在配置范围 |
| `update(dt)` | 推进平滑，显式应用相机变换 |
| `snap()` | 立即对齐配置，不依赖 dt |
| `syncFromCamera()` | 从当前相机世界位置推导角度和距离，切换控制器时使用 |
| `enabled` | false 时 update 不改变相机 |
| `dispose()` | 释放控制器引用，不销毁相机 |

`damping` 为非负每秒速率，默认 12。使用 `1-exp(-damping*dt)` 趋近目标，零表示直接对齐；dt 为零时不推进，首次尚未初始化时允许建立初始相机姿态。参数必须有限，距离必须为正，俯仰上下限必须严格位于 -90～90 度内。

控制器在世界空间求位置，通过新增 `Camera3D.lookFrom(worldPosition, worldTarget, up=null)` 一次设置相机。相机挂在有旋转、缩放的父节点下时，会抵消父变换；不可逆的相机父矩阵仍明确报错。lookAt 继续保留，并复用 lookFrom。相同姿态不重复标记相机矩阵失效。

一个相机同一帧只应由一个控制器驱动。控制器不改变相机 FOV、近远裁剪面或 Scene3D 尺寸，也不会自行注册帧回调。

## 跟随相机

```haxe
var follow = new hx.controls3d.FollowCameraController3D(camera, model);
follow.targetOffset.setTo(0,1.5,0);
follow.distance = 8;
follow.pitch = 22;
follow.snap();
```

FollowCameraController3D 继承环绕控制器，保留旋转、缩放和平滑接口。每次更新先读取 targetNode 的世界位置，加上世界坐标 targetOffset，作为环绕中心。偏移不跟随角色朝向旋转，也不随角色缩放放大。

`targetNode=null` 或目标已销毁时安全停止跟随；切换目标默认沿用当前平滑状态，需要立即对齐时调用 snap。目标不得是相机自身或相机的子节点；相机与目标都已经属于场景时，必须属于同一个 Scene3D。

建议业务顺序为：角色位移 → 动画与蒙皮 → 当前相机控制器 update → 渲染。同一模型不因阴影、相机或视口查询重复推进动画。

## 视口输入适配

```haxe
var input = new hx.controls3d.Scene3DInput(scene, orbit);
input.dragThreshold = 5;
input.rotationSensitivity = 0.35;
input.zoomSensitivity = 0.1;
input.addEventListener(hx.events.Scene3DInputEvent.SELECT,
    function(event:hx.events.Scene3DInputEvent) {
        if (event.hit != null) trace(event.hit.model);
    });
```

只有 Scene3D 实际收到的有效左键按下或 TOUCH_BEGIN 才启动捕获。覆盖视口的二维 UI 不会启动三维操作；滚轮同样须由该视口接收。控制器可为 null，此时仍支持选择和拖动判定。

移动超过 dragThreshold 后开始旋转；拖动释放不会触发选择。轻点必须在同一视口收到本次对应的抬起事件后才派发 SELECT。触摸按 touchPointID 匹配，其他触摸点不会改变当前捕获；触摸结束附近的合成鼠标按下在该适配中短暂抑制。当前提供单指拖动，不提供双指缩放手势。

选择的射线、命中和舞台坐标在有效按下时固定，抬起确认轻点后才派发 SELECT，避免镜头平滑转动或角色动画改变点击目标。开始拖动、取消、禁用或销毁时清除该快照；抬起被 UI 拦截时最迟在下一次视口 UPDATE 清除。已销毁的命中网格不会再作为有效 hit 返回。只在按下时存在 SELECT 监听才查询，不在抬起时重复拾取。

同一左键既负责点击又负责拖动，需要先确认手势，不在按下时直接下达移动指令，也不等待相机平滑完成。业务使用返回射线设置目标后，由后续业务更新推进位移。

| 事件或状态 | 含义 |
| --- | --- |
| `Scene3DInputEvent.SELECT` | 完成轻点；hit 可为空，ray、hit 和舞台坐标对应按下时的拾取快照 |
| `DRAG_BEGIN / DRAG_END` | 达到拖动阈值、完成拖动 |
| `CANCEL` | 当前捕获取消，reason 描述原因，不触发选择 |
| `capturing / dragging / pointerId` | 捕获状态及最近捕获 ID；鼠标使用 -1，触摸使用后端提供的 ID，未捕获时 ID 不表示仍持有指针 |
| `enabled=false / cancel(reason)` | 结束捕获；再次启用需要新的有效按下 |
| `controller` | 可显式切换当前控制器；只操作与视口当前相机一致的有效控制器 |

捕获中的移动和抬起通过 Stage 新增的 `addPointerCaptureListener / removePointerCaptureListener` 在普通 UI 冒泡前观察。观察器只读源事件，不改写、取消或重新派发输入；已有命中、菜单与冒泡规则保持原样。这样拖动跨过消费事件的 UI，或进入另一个视口后释放，也能正确结束，另一视口不会凭空开始操作。

抬起候选仅保留到当前输入路由或下一次视口 UPDATE，避免持续持有被覆盖 UI 的事件引用。Stage 失焦、尺寸变化、视口移出舞台和禁用适配都会取消捕获；视口销毁自动 dispose 适配。业务仍应在场景释放时主动 dispose 输入适配，再释放控制器、三维节点与 Assets。

新增 TOUCH_CANCEL 可由后端或自定义输入桥经 Stage 转发。当前不新增原生窗口离开、原生触摸取消监听；若宿主没有送达抬起、失焦或取消，业务可显式调用 input.cancel。不能仅凭此处的模拟断言认定所有设备都具备相同的原生事件转发行为。

## 统一射线查询

| API | 输入与裁剪 |
| --- | --- |
| `Scene3D.stageToViewport(stageX,stageY)` | 舞台坐标转逻辑视口坐标；视口外、隐藏或二维变换不可逆时返回 null |
| `Scene3D.stageRay(stageX,stageY)` | 舞台坐标生成世界射线，起点位于相机近裁剪面；无有效视口或相机时返回 null |
| `Scene3D.pick(stageX,stageY,maxDistance=null,filter=null)` | 保留旧的两参数调用，增加最大距离和网格过滤；保留视口与近远裁剪 |
| `Scene3D.raycast(ray,maxDistance=null,filter=null)` | 世界射线查询当前三维节点树，不使用相机近远裁剪或二维视口可见性 |
| `Raycaster3D.intersect(root,ray,maxDistance=null,filter=null)` | 查询任意三维节点子树，可以不属于舞台 |

maxDistance 以射线起点为零，使用世界距离，null 表示不额外限制。filter 是只读的 MeshObject 谓词，不应在其中销毁、挂接或修改参与查询的节点。过滤掉父网格并不自动过滤它的子网格。

几何查询先检查包围盒，再求最近三角形命中。返回 object、世界位置、世界距离、三角形编号、局部 UV，以及新增的 model 属性。model 沿命中对象父链解析最近的 Model3D，因此挂在骨骼下的道具也能选中所属角色。

查询读取当前 Geometry3D.positions 和节点世界矩阵，与当前 CPU 蒙皮及刚性蒙皮兼容。不可逆或退化网格跳过；几何按双面检测，不读取 Alpha，不自动检查覆盖 UI 或祖先二维遮罩。UI 路由保护属于 Scene3DInput，而不是原始射线函数。

二维缩放、旋转和嵌套父变换通过视口逆矩阵转换；stageRay/pick 会刷新舞台变换再查询。Camera3D.screenRay 接受相机逻辑视口内坐标，两者的坐标语义不同。

## 地面求交

```haxe
input.addEventListener(hx.events.Scene3DInputEvent.SELECT,
    function(event:hx.events.Scene3DInputEvent) {
        if (event.hit != null) return;
        var distance = event.ray.intersectPlane(new hx.geom.Vector3D(0,1,0), 0, 100);
        if (distance != null) {
            var point = event.ray.at(distance);
            // 在项目逻辑中将 point 作为移动目标。
        }
    });
```

平面使用 `normal·point + constant = 0`，返回非负世界距离；平行、共面、背向或超出最大距离时返回 null。平面没有有限边界，示例自行将地面目标限制在 X/Z ±10 的范围内。地面射线求交不隐式继承相机 far，需要时由业务设置最大距离。

## 验收与限制

助手仅进行源码静态审阅与差异格式检查；示例的通过结论来自用户反馈，可选断言尚无独立执行记录。

用户在示例目录执行 `arch -x86_64 lime test html5`，检查环绕、跟随、滚轮、动画角色及挂件选择、地面移动、二维 UI 覆盖、跨视口拖动、变换后的视口、重复加载与重新进入。

可选 `-D hxmaker_camera_checks` 准备了相机世界变换、平滑时间切分、射线距离与裁剪、节点过滤、挂点所属模型、输入隔离、触摸 ID、取消和释放的数值断言，尚无独立执行记录。通过标记为 `HXMAKER_CAMERA_INTERACTION_CHECKS PASS`。

本次追加相机平滑中轻点使用按下快照、舞台坐标与射线一致、左键拖动继续旋转且不触发移动、释放后普通鼠标移动不再旋转的回归断言，均未运行。用户复测时先左键拖动并释放，在镜头仍平滑转动时轻点地面；角色应前往按下时对应的目标。再次拖动应正常旋转且不误下达移动指令；点击二维 UI 不应设置目标。

本轮不加入相机碰撞、正交相机、GPU 选择缓冲、BVH、物理和导航；角色移动是示例业务。多纹理仍按材质与渲染状态兼容规则工作，两个 Scene3D 各自合批、各自拥有深度目标，不能跨视口共享同一个批次。

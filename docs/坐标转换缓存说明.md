# 坐标转换缓存

`localToGlobal`、`globalToLocal`、`touchX/touchY`、`mouseX/mouseY`、相对边界和 `Scene3D.stageToViewport` 的矩阵同步改为按需检查祖先链，不再通过坐标查询调用舞台的整树变换更新。

## 标记职责

- `__transformDirty` 保留给渲染器，坐标查询和矩阵计算都不清除此标记。
- `__worldTransformDirty` 表示当前节点的世界矩阵和世界透明度缓存失效；计算完成后只清除此标记。
- `__worldTransformVersion` 与缓存的父节点版本一起识别祖先变化。容器移动时无需递归标记全部后代，同一帧内再次修改祖先也能立即反映到查询结果。
- 缓存记录参与计算的父对象，支持重新挂载、脱离舞台及离屏更新后的坐标恢复。

稳定布局下，每次查询检查的节点数与显示树深度有关，矩阵仅在缓存失效时重算。查询仍会按原有规则结算遇到的待处理布局，因此首次布局或布局失效时可能继续产生子树测量成本。正式渲染仍保留整树更新流程。

`Image` 的裁边偏移、文字对齐原点继续参与世界矩阵。直接修改 `transform` 的矩阵分量或 `Image.data.frameRect` 的偏移，也能在下一次查询时识别。`mouseX/mouseY` 的逆变换同时使用舞台的 X、Y，修正旋转或错切时只传一个分量的问题。

## 复用输出点

原有单参数调用方式保持有效，默认返回新点。高频调用可以传入输出点：

```haxe
var result = new Point();
display.localToGlobal(input, result);
display.globalToLocal(result, result);
```

输入输出使用同一个点时，计算先保存输入的两个分量，再写入结果。粒子发射点转换已使用每个粒子自己的临时点复用，只减少分配，每次仍重新读取发射器位置，没有引入按帧坐标缓存。

## 接口与职责

碰撞代理共用 Collider3D 的节点、偏移、碰撞层、启用、触发与资源所有权规则。BoxCollider3D 保留构造、尺寸与世界 AABB 语义。新增 RampCollider3D 表示封闭凸楔形坡道，提供精确斜面的球体／竖直胶囊重叠与连续扫掠、射线查询。

CollisionWorld3D 的 add 仍返回传入代理的具体类型；colliders 和 CollisionHit3D.collider 现在使用共同的 Collider3D 类型。如果项目曾将这两个返回值直接声明为箱体，需要改用共同类型，或先判断形状类型再转换。已有创建箱体、设置属性、注册和查询的调用保持可用。

世界负责过滤候选、扫掠包围盒初筛和保守推进，代理负责窄相位距离与射线。仍不引入全局更新器，不修改鼠标映射、渲染接口、帧调度或多纹理合批。

## 坡道代理与几何

```haxe
var geometry = hx.geometry.RampGeometry.create(3, 2.2, 6);
var mesh = new hx.display.MeshObject(geometry, material);
scene.root.addChild(mesh);
mesh.setPosition(1, 0, -2);

var ramp = new hx.collision3d.RampCollider3D(3, 2.2, 6, mesh);
world.add(ramp);
```

几何和代理采用相同局部坐标：X 为宽度，Z 从 -depth/2 到 +depth/2，底面 Y=0；顶面从局部 -Z 的零高度升至 +Z 的 height。该坐标与中心在原点的 BoxGeometry 不同，绑定节点应位于坡道底面基准位置。

RampCollider3D 的 size 和 offset 可修改；绑定节点支持可逆的旋转、非均匀及负缩放。代理将顶点和面变换到世界空间，重新计算朝外法线，在世界空间与竖直胶囊求距；变换、尺寸和偏移未改变时复用坡道数据。零缩放、退化面或数值溢出明确报错。

坡道的 AABB 仅用于初筛，其包围盒中的空区域不会当成实体。球／胶囊中心线未进入凸体时，使用线段到八个表面三角形的最近距离；中心线进入实体时按可分离面保守推出。射线按封闭凸体裁剪，起点在实体内时 distance=0。该代理不是通用三角形网格或任意凹地形碰撞。

RampGeometry 与代理相互独立，业务仍需同步尺寸。代理不拥有渲染几何；退出时注销／销毁代理，再销毁节点并释放自建几何和材质。

## 角色设置

```haxe
var control = new hx.controls3d.CharacterController3D(world, model, 0.35, 1.9);
control.stepOffset = 0.45;
control.maxSlopeAngle = 45;
control.groundSnapDistance = 0.45;
var result = control.update(dt, new hx.geom.Vector3D(0, 0, 3));
```

| 设置或结果 | 含义 |
| --- | --- |
| stepOffset | 脚底允许跨越的高度，默认 0；为零时不启用主动跨步 |
| maxSlopeAngle | 允许坡度，单位为度，范围为 0～90，不含 90；是既有 minGroundNormalY 的角度接口 |
| minGroundNormalY | 继续保留，maxSlopeAngle 与其互相换算；默认 0.7 约为 45.57°，示例显式设为 45° |
| groundSnapDistance | 向下贴地距离，沿用既有设置；下台阶需要覆盖对应级差 |
| result.groundNormal | 已确认的实际支撑面法线，无支撑时为空 |
| result.stepped | 本次成功采用了跨步路径；不代表整组楼梯已通过 |
| result.slopeLimited | 本次接触触发了陡坡攀爬限制 |

CollisionHit3D 新增 surfaceNormal。normal 仍为胶囊与代理的分离方向，适合滑动与推出；surfaceNormal 描述实际面方向，用于判断地面与坡度。箱顶圆角接触可以返回向上的支撑面方向，坡道返回对应真实面的方向，避免把球形边缘法线误当成坡道角度。

可行走支撑面上的移动保持请求的世界 X/Z 分量，由面方程补足 Y。站立时不把重力不断投影成缓坡下滑；坡面间过渡仍按扫掠和向下探测确认。未起跳时才贴地，上升时保持空中运动。离开支撑范围后继续重力下落。

超过坡度上限的朝上表面不会成为 grounded 支撑，并额外限制朝坡上方的水平分量。真实接触面仍用于碰撞响应，空中接触陡坡可受重力滑落。胶囊尺寸固定在世界空间，不跟随坡面倾斜。

## 跨步规则

主动跨步只在脚底附近存在有效支撑、请求未上升、横向运动碰到障碍时尝试。按以下顺序对整只胶囊扫掠：

1. 升高 stepOffset 加少量接触余量，确认头顶空间。
2. 在抬高位置执行尚未完成的水平位移；存在下一处阻挡时只走到其接触点。
3. 向下寻找坡度合格的支撑，检查实际升高、落脚表面高度、水平进展及最终无穿插。

试探失败不修改真实节点，继续原有阻挡／滑动。成功时保留已确认的位置，设置 stepped 和 grounded。空中、过高台阶、没有落脚面或头顶不足时不会主动跨步。当前试探要求完整配置升高量的头顶空间，属于保守策略。

本次未加入视觉脚步平滑或台阶高度插值；胶囊脚底会按碰撞结果升降。目标在墙后或陡坡后仍可持续尝试移动，寻路由后续阶段负责。胶囊自身的圆角可能自然滚过很低的边缘，因此 stepOffset=0 不代表所有微小边缘都成为直角墙。

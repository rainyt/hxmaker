# 阴影质量与级联使用说明

本轮修改覆盖 hxmaker 核心库与 hxmaker-openfl 后端。已完成源码走查和数值检查入口准备；按项目约定，没有执行编译、数值检查或 GPU 验证。

## 默认行为

开启主方向光阴影后，默认采用两级方向光阴影、稳定包围球取景、纹素对齐和按亚纹素位置加权的 PCF4。覆盖距离默认 100 个世界单位，实际不超过相机 far；不再使用之前容易让拉远目标脱离覆盖的 30 单位默认值。距离末端最后 10% 平滑淡出；超出配置范围的阴影仍会消失，这是明确的覆盖预算。

```haxe
light.shadowEnabled = true;
light.shadowMapSize = 2048;
light.shadowCascadeCount = 2;
light.shadowDistance = 100;
light.shadowFadeRatio = 0.1;
light.shadowFilter = hx.light.ShadowFilter3D.PCF4;
```

`shadowDistance=0` 表示覆盖至 camera.far。相机 far 很大时不宜盲目启用此模式，否则有限阴影分辨率会被摊薄。近、远裁剪面仍须按实际场景设置，主画面的深度冲突与阴影采样密度是两个独立问题。

## 移动镜头时的稳定性

每级根据截断相机视锥计算包围球，再使用光空间正方形覆盖其 XY。相机旋转不会像紧密 AABB 那样不断改变取景宽高；相机移动时中心对齐阴影纹素。相机视场角、视口比例、级联距离或相机缩放发生变化时，取景大小仍会相应变化。

近远切分混合均匀与对数切分。远级联从近级联末段开始，交界约占近级联深度跨度的 15%；片元按生成时相机的前向深度选择级联，并在交界区混合两个阴影结果。有效远级联也用于近级联未覆盖位置的回退。

只剔除不能沿光线影响任何级联的投影物。镜头外、光源上游的投影物仍保留，并按需扩展阴影深度；远处物体不会撑大 XY 范围。当前筛选使用保守包围盒，不是精确到三角形的可见性判断。

## 过滤与偏差

PCF4 对最近四个阴影深度进行比较，再根据亚纹素位置双线性加权，避免旧的等权平均只有五档亮度。深度纹理自身继续使用 NEAREST，避免错误地先插值深度再比较。两级横向排列成图集，采样夹在各自区域的半纹素边界内，不跨级联串色。

默认 `shadowBias=0.0001`、`shadowSlopeBias=0.0005`，仍以归一化阴影深度为单位；原有显式赋值会继续生效。新增 `shadowNormalBias=0.5`，按每级阴影纹素的世界尺寸沿几何法线偏移，并随入射角调整，以减轻自阴影。薄壁、双面材质或不同尺度场景仍可能需要调整这些参数，过大偏差可能产生悬浮感。

WebGL 2 / GLES 3 会尝试 24 位阴影深度，附件不完整时回退到 16 位；WebGL 1 保留 16 位兼容路径。这里只升级阴影深度，主场景深度目标没有改变。

## 资源、缓存与兼容

两级共用一张横向图集和一个阴影纹理槽位，`shadowMapSize` 表示每级边长。实际边长受设备的纹理与视口上限约束，并向下取二次幂。两级配置会增加投影物的绘制与上传，交界位置最多执行两次 PCF4，即八次深度采样。若双级图集分配失败，会先尝试同分辨率的单级阴影；成功回退后不逐帧重复分配，调整 shadowMapSize 或调用 requestShadowUpdate() 后重试双级。

相同每级分辨率下，双级附件像素数约为单级的两倍。每级 2048 时，16 位深度加兼容颜色附件估算约 48 MiB；24 位深度按每像素 4 字节存储估算，总计约 64 MiB。实际驱动占用可能不同。

低成本设备可使用：

```haxe
light.shadowCascadeCount = 1;
light.shadowMapSize = 1024;
```

固定 `shadowBounds` 仍使用单级世界范围，不应用自动距离淡出。`shadowAutoUpdate=false` 保留生成时的矩阵、选择相机和距离参数，相机移动不会让冻结阴影因重新筛选而突然丢失；需要更新时调用 `requestShadowUpdate()`。改变贴图布局或重新创建 GPU 上下文仍会重建。

自动缓存比较实际投影矩阵与投影物版本；纹素对齐后投影完全一致的相机微移可以复用阴影图。新的级联选择相机和淡出参数仍会同步，接收物材质变化无需重绘投影内容。

## 诊断与待验证

`scene.stats` 新增：

- `shadowCascades`：实际级联数量。
- `shadowDepthBits`：阴影深度位数。
- `shadowWorldTexels`：各级每个阴影纹素的世界尺寸，越小代表空间采样越密。

`shadowMapSize` 为每级实际边长；`shadowMapBytes` 包含图集的全部级联，按深度和颜色附件估算。绘制、三角形与上传统计会累加全部级联。

`test/DirectionalShadowFitChecks.hx` 已补充旋转时尺度稳定、远级联覆盖和配置兼容检查，尚未执行。用户安排后应验证：完整环绕及拉远镜头、跨级联边界、覆盖末端淡出、MASK 与镜头外投影物、单级与固定范围、手动冻结、多场景及上下文恢复，并检查 GL 错误和移动设备开销。源码实现完成不等于这些 GPU 行为已经验证通过。

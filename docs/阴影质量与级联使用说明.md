# 阴影质量与自动配置

2026-10-18 新增自动阴影规划、质量档位、显式覆盖跟踪、按级偏差和独立级联缓存，涉及 hxmaker 核心与 hxmaker-openfl 后端，两个库需要同步更新。本轮按项目约定未运行编译或测试；此前 PCF4 / PCF9 的实测记录不能视为新自动规划实现的验收结果。

## 普通用法

```haxe
light.shadowEnabled = true;
mesh.castShadow = true;
// receiveShadow 默认 true，接收物还需使用光照材质。
```

默认采用 `ShadowQuality3D.BALANCED`，引擎规划范围、级联和偏差。可选切换档位：

```haxe
light.shadowQuality = hx.light.ShadowQuality3D.HIGH;
```

| 档位 | 自动每级边长 | 自动过滤 | 自动附件预算上限 |
| --- | --- | --- | --- |
| PERFORMANCE | 512 | HARD | 8 MiB |
| BALANCED | 紧凑单级 2048；相机两级 1024 | PCF4 | 32 MiB |
| HIGH | 2048 | PCF9，半径 1.25 | 64 MiB |
| LEGACY | 请求默认值 1024 | 请求默认值 PCF4 | 沿用显式尺寸和设备上限 |

预算按每像素 8 字节保守估算，不读取设备显存。显式设置的尺寸优先于自动预算，实际仍受设备上限和分配回退限制。档位不会按瞬时帧率自动跳变。两级共用横向图集，只占一个公共纹理槽位；多纹理合批继续生效。

## 自动范围与稳定性

规划器先识别主相机可见的投影物，将接收包围盒的六个面裁剪到投影物的光空间列，估计有效接收深度。大地面整体远端不会直接决定覆盖距离。随后按光空间范围筛选可能影响局部覆盖的投影物，保留镜头外上游物体。

投影区域相对当前视锥足够紧凑时采用单级范围，接收物仅扩展深度，不扩张投影物的 XY；适合球阵列、模型展示等局部场景。区域较大时采用相机局部范围和一到两级阴影，保留稳定包围球与纹素对齐。显式距离、级联数或非空切分比例使用相机范围；`shadowBounds` 始终优先并采用单级。

自动尺度按四分之一个倍频程向上量化，需要扩张时立即应用，缩小持续满足阈值 0.75 秒后应用。紧凑模式进入和退出使用不同阈值，避免临界位置反复切换。规划只在三维场景重绘时推进；完全静止并复用场景纹理时不会启动额外计时任务。

该实现基于保守包围盒，不读取 GPU 深度，也不精确分析所有三角形。大型合并网格、极端视角和小而分散的远近目标仍需验收，必要时可显式给出覆盖距离或世界范围。它不承诺在任意尺度和有限预算下消除全部锯齿。

## 显式覆盖与恢复自动

优先级为：手动世界范围决定取景；各项显式设置覆盖质量档位；其余设置由自动规划解析。赋值与旧默认值相同也会记录为显式覆盖。

```haxe
light.shadowQuality = hx.light.ShadowQuality3D.HIGH;
light.shadowMapSize = 1024; // 明确限制每级尺寸，HIGH 不会覆盖它。
light.shadowFilter = hx.light.ShadowFilter3D.PCF4;

light.resetShadowOverrides("shadowMapSize"); // 仅恢复尺寸自动选择。
light.resetShadowOverrides(); // 恢复所有自动项，并清除 shadowBounds；保留质量档位。
```

灯光上的旧字段读取的是请求值，不是后端解析结果。例如没有显式设置尺寸时，`light.shadowMapSize` 仍返回请求默认值 1024，实际单级可能为 2048。实际结果应读取 `scene.stats`。动态反射赋值应使用 `Reflect.setProperty`，以执行覆盖跟踪的属性 setter。

若需旧版固定 100 单位、默认两级和固定归一化偏差：

```haxe
light.shadowQuality = hx.light.ShadowQuality3D.LEGACY;
```

这是视觉行为的兼容入口。原有显式距离、级联数、过滤和偏差保持有效；开启新默认自动配置可能改变未显式设置项的画面。

## 过滤、偏差与覆盖边界

PCF4 对最近四次深度比较结果做双线性加权，PCF9 使用九次帐篷加权比较；深度纹理本身仍为 NEAREST。PCF9 半径范围 0～1.5，仅影响 PCF9；0 退回硬采样，1 接近 PCF4，1.25～1.5 加宽柔化。核不会跨越图集中的级联边界。过滤只能柔化采样轮廓，不模拟真实面积光半影，也不会平滑模型的几何折线。

非交界常见路径每级分别执行四次或九次采样；两级交界最多八次或十八次，回退选择也可能采样两级。更宽的核需要更高采样预算，不能仅提高当前九采样半径上限。

自动深度偏差由每级世界纹素尺寸换算到该级深度跨度，并考虑深度位数；斜率偏差同时考虑过滤核。法线偏差仍随世界纹素尺寸调整。显式 `shadowBias`、`shadowSlopeBias` 保持归一化深度单位，不被自动值覆盖。偏差和法线偏移仍需在薄壁、双面或极端光向场景中验收。

相机模式默认保留覆盖末端 10% 淡出和近级联跨度 15% 交界混合；紧凑和手动范围没有相机距离截止。用户仍可覆盖 `shadowFadeRatio`、`shadowCascadeBlend`、`shadowCascadeSplit`，其中 split 为整个 near～end 深度跨度的 (0,1) 比例，null 为自动混合均匀与对数切分。

## 缓存与资源回退

各级分别比较矩阵和实际投影物状态，只通过 scissor 清理失效图集区域。不透明材质的粗糙度、颜色等变化不会要求重绘阴影；MASK 继续跟踪材质版本，以捕获纹理像素和裁剪变化。阴影图复用不影响主场景重新绘制。

`shadowAutoUpdate=false` 保留生成时的矩阵、级联选择相机和布局；需要同步时调用 `requestShadowUpdate()`。首次生成、布局变化和上下文重建仍会重绘。固定世界范围不会仅因相机移动而失效。

实际尺寸按设备能力向下取二次幂；分配失败先尝试同尺寸单级，再逐级降低边长。成功降级后记住当前请求的结果，不逐帧重复申请；改变尺寸、规划布局或请求更新后重新尝试。完全失败保留光照并关闭阴影。

WebGL2 / GLES3 优先使用 24 位阴影深度，失败回退 16 位；WebGL1 保留 16 位路径。当前附件仍包含兼容颜色纹理，因此两级 2048 的 WebGL2 估算占用约 64 MiB，单级约 32 MiB。

## 诊断与待验收

`scene.stats` 提供：

- `shadowFitMode`、`shadowEffectiveDistance`：实际模式和相机覆盖终点，紧凑/手动模式距离为 0。
- `shadowMapSize`、`shadowCascades`、`shadowDepthBits`、`shadowMapBytes`：实际分辨率、数量和资源占用。
- `shadowWorldTexels`：各级世界纹素尺寸。
- `shadowEffectiveFilter`、`shadowEffectiveFilterRadius`：实际过滤配置。
- `shadowCascadeUpdated`：本次重绘各级是否更新；`shadowCacheHit` 表示所有级联均复用。
- `shadowDepthBiases`、`shadowSlopeBiases`：实际各级归一化偏差。
- `shadowDegradation`、`shadowStatus`：回退原因和启用状态。

统计保留最近一次重绘结果，判断本帧提交还需检查 `redrawThisFrame`。

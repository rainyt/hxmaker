# PBR 材质对比

展示 Lambert、PBR 非金属和 PBR 金属三类材质，以及粗糙度对高光的影响。

镜头复用 `OrbitCameraController3D` 和 `Scene3DInput`：

- 视口内按住鼠标左键或单指拖动，旋转观察方向；滚轮缩放。
- “拉近镜头”“拉远镜头”可用于鼠标或触屏缩放。
- “镜头复位”恢复初始位置，并停止自动环绕。
- “自动环绕”切换自动运镜，开始拖动、滚轮或按钮缩放后自动关闭；再次开启时从当前角度继续。
- 距离限制为 4～30，俯仰角限制为 5°～80°，避免镜头穿入地面；不包含双指缩放。

阴影仅设置 `shadowEnabled=true` 和可选的 `ShadowQuality3D.HIGH`，由引擎自动规划范围、级联、过滤与偏差，不再手写包围盒。底部增加实际取景模式、每级尺寸、级联数量与世界纹素尺寸，便于检查结果。质量档位和覆盖规则见[自动阴影说明](../../../docs/阴影质量与级联使用说明.md)。这次自动配置改动尚未运行编译或画面验证。

DrawCall 对比按钮：

- “统一 PBR 参数”：10 个 PBR 球均设为金属度 0、粗糙度 0.5，保留各自独立材质实例。
- “恢复原始参数”：恢复两行球各自的金属度，以及各列原始粗糙度。
- 切换参数时停止自动环绕，保持观察位置。底部分别显示主场景、阴影和二维合成批次。
- 全部球体可见、无额外拆批时，主场景预计从 11 批降到 2 批，恢复后回到 11 批；这是源码推算，尚未实测。阴影缓存命中时阴影批次可能为 0，全局 FPS 中的 DrawCall 还可能包含文字等二维内容。

需要使用本轮 hxmaker 与 hxmaker-openfl 开发源码。入口继承 `HxmakerApplication`；示例自带程序生成的摄影棚环境资源，无需下载第三方素材。

第二阶段新增静态 IBL 环境光照与反射：

- 默认加载自带摄影棚的预积分图集，支持环境开关、亮度增减、旋转与复位。
- 金属获得环境反射；不同粗糙度采样不同预过滤层，非金属获得环境漫反射与镜面贡献。
- 环境占用一个公共纹理槽，不增加独立绘制通道，统一材质参数的对比仍可使用。
- 底部显示主场景、阴影、合成批次，以及环境状态、强度和角度。
- 第三阶段已补充 PBR 数据贴图和法线贴图；仍不提供动态物体反射。独立天空背景见[天空环境示例](../skybox/README.md)。环境图集为 8 位线性范围编码，极端 HDR 明暗比有精度限制。

环境资源可通过仓库中的 `tools/bake-ibl.py` 重新生成，或从自定义 2:1 HDR / PNG / JPEG 全景图烘焙；参数与布局见使用说明。

第三阶段新增内嵌 GLB 贴图示例：

- 点击“贴图示例”切换原球阵列与贴图球，默认保持原球阵列。
- 金属粗糙度、法线、AO、自发光各有独立开关，基础色保留。
- GLB 同时演示独立采样设置、切线导入及资产持有图片的生命周期。
- 统一／恢复 PBR 参数会切回原球阵列，继续用于批次对比。
- 从仓库根目录运行 `python3 tools/generate-pbr-sample.py` 可重新生成内嵌 GLB 与独立 PNG。

用户已确认第二阶段测试通过；第三阶段尚未编译或运行。详细接口、限制和待验证项目见[使用说明](../../../docs/PBR材质使用说明.md)。

# 天空环境验证记录（2026-10-18）

## 实现范围

核心仓库提供 `SkyboxTexture3D`、`Skybox3D`、`SkyEnvironment3D`、场景接入和独立统计。配套 hxmaker-openfl 增加 `SkyboxPass3D`，在主目标清屏后、模型绘制前提交全屏天空。资源工具支持全景、HDR 和六面输入，分别输出高清天空与旧格式 IBL。示例入口继承 `HxmakerApplication`。

本机默认 `haxe` 指向缺少标准库配置的 SDK 包装器；主编译使用已有的 `/usr/local/bin/haxe`。示例编译沿用 `arch -x86_64 lime build html5`。

资源工具回归验证六面中心方向、跨面边缘连续性、全景周期边缘、天空边框、HDR 辐射编码、六面输入校验、旧 CLI 行为及仅输出天空模式。

浏览器验收覆盖：

1. 核心参数校验、天空与 IBL 联动旋转、共享图片的参数隔离及借用生命周期。
2. 无模型、无 PBR 材质时绘制天空，天空批次独立于网格批次。
3. 关闭自动重绘后复用离屏纹理。
4. 相机平移、近远裁剪不改变天空，FOV 变化影响边缘视野。
5. 旋转、曝光、开关、无相机回退及共享资源版本传播。
6. 普通非二次幂全景图六向颜色、极点与横向接缝的 GPU 读回。
7. 旧 IBL 图集第零层的天空复用。
8. 不透明模型遮挡、透明模型混合与 Bloom 接入。
9. 强制降低后端精度能力后，低精度着色器绘制及亮度超限回退；强制降低纹理上限后的尺寸回退与恢复。
10. WebGL 上下文丢失与恢复后的离屏像素一致性。
11. 解除主视口配置后，共享天空的另一个视口继续有效。

已人工检查示例截图和默认路径上下文恢复后的画面。验收宏中的 GPU 读回与浏览器命令入口不进入普通构建。

浏览器为 Chrome 155.0.8059.80，使用 SwiftShader 软件 WebGL。报告记录了实际 WebGL 版本与 VAO 状态：

- [WebGL 1 无 VAO 报告](../samples/3d/skybox/Validation/2026-10-18-webgl1-no-vao.json)

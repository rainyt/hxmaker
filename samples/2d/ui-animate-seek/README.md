# UIAnimate 时间定位示例

本示例供手动验收 `UIAnimate.seek()` 和 `UIAnimateGroup.seek()`。代码位于 Hxmaker 分支 `codex/ui-animate-seek`，本次未执行编译、启动或测试，下面的结果均为预期行为。

## 启动

本机 Haxelib 的 `hxmaker` 已指向当前仓库，无需重新设置。进入本目录后执行：

```sh
cd /Users/rainy/Documents/haxelib-self/rainyt/hxmaker/samples/2d/ui-animate-seek
haxelib run lime test html5
```

其他机器需先安装项目使用的 `hxmaker-openfl`、`spine-haxe`、`actuate` 及其 OpenFL / Lime 依赖，并确保 `hxmaker` 指向包含本功能的仓库。启动入口继承 `hx.core.HxmakerApplication`，业务逻辑位于 `Source/GameStage.hx`。

## 新增接口

```haxe
// 包含 delay 的时间，单位统一为秒；调用后保持静止。
animate.seek(0.75);

// 动画组使用统一时间原点。
timeline.seek(1.5);

// 单动画为 delay + duration；动画组取各子动画总时长的最大值。
var length:Float = timeline.totalDuration;
```

- `seek()` 会停止本动画通过 `play()` 创建的补间，不触发完成回调，不自动继续播放；同目标上的其他独立补间保留。原有 `stop()` 仍保留停止目标全部补间的行为。
- 负时间按零处理；超过末尾保持结束值。`delay` 前保持起始值；零时长动画在到达 `delay` 时直接应用结束值。
- 使用与播放相同的 `IEasing`；未指定 `ease` 时使用 `Actuate.defaultEase`，其默认值为 `Expo.easeOut`。
- 首次 `seek()` 或 `play()` 会在尚未初始化时调用 `updateOption()`，捕获省略的起止值。后续前后定位复用这些基准。需要重设基准时，在恢复目标的静态姿态和完成布局后显式调用 `updateOption()`。
- 对同一目标的同一属性，选择已经开始且 `delay` 最大的片段；起点相同时以后声明的片段为准。尚无片段开始时使用最早片段的起始值；片段之间的空白区间保持前一段结束值。
- `seek()` 的时间必须为有限数值；参与定位的时长和延迟必须为非负有限数值，属性起止值必须为有限数值，否则抛出中文错误。
- 空组时长为零，定位不修改画面。通过代码添加的嵌套组共用时间原点；组自身的 `duration`、`delay`、`ease` 沿用旧行为，不参与调度。XML 构建器仍只解析组内的直接 `<animate>` 子节点。

## 手动验收

启动后六行方块保持时间零的姿态。首行蓝色方块会持续上下伸缩，这是单独的 Actuate 补间，用来观察 seek 是否误停其他动画。

| 操作 | 预期结果 |
| --- | --- |
| 点击 `0 秒` | 蓝、橙、紫、绿、粉、黄的 x 均为 220；橙色旋转为 0；绿色透明度为 0.2 |
| 点击 `0.5 秒` | 蓝色 x 为 400；橙、粉仍为 220；紫色 x 为 400；绿色刚开始；黄色比蓝色更靠右 |
| 点击 `1 秒` | 蓝色 x 为 580、透明度为 0.7；紫色 x 为 580；橙色刚开始；粉色瞬间跳到 940 |
| 拖动到 `1.25 秒` | 紫色保持 x=580，处于两段之间的间隔，不被未来片段提前覆盖 |
| 点击 `1.5 秒` | 紫色从 x=580 开始第二段；橙色 x=580、旋转 90 度；绿色 x=580、透明度约 0.525 |
| 点击 `2 秒` | 紫色 x=760；蓝、橙、粉、黄均到达 x=940；绿色仍在移动 |
| 点击 `2.5 秒` | 所有方块 x 均为 940；绿色透明度为最初捕获的 0.85 |
| 点击 `4 秒`、`-1 秒` | 分别保持末尾、开头，不发生越界外推 |
| 反复拖动至末尾、开头、中间 | 相同时间应得到相同的 x、旋转和透明度，绿色的结束值不漂移 |
| 点击“正向预览”，然后“暂停” | 时间轴通过逐帧调用 seek 前进；暂停后位置保持，独立上下伸缩继续 |
| 点击“反向预览” | 时间轴递减至零；与手动定位到同一时刻的结果一致 |
| 点击“原生播放首行”，播放中点击 `1 秒` | 只有首行原生播放；定位后回到 x=580 并保持，不再被旧补间拉走，上下伸缩继续 |

底部显示各方块的实际 x 和绿色透明度，便于直接比对数值。示例不会自动判定或报告测试通过。

## 当前边界

- 本次扩展提供时间求值与静态定位，没有新增关键帧 XML 格式、暂停恢复接口或串行播放器。“正向预览”和“反向预览”由示例自行递增或递减时间并调用 seek。
- 动画组原有 `play()` 的并行播放行为保持不变；同属性分段示例用于验收 seek 的确定性，不代表旧播放器已经具备同样的分段调度能力。
- 定位后沿用正常播放的父级 `updateLayout()` 规则；受锚点、百分比或自动排列控制的 x、y、width、height 仍可能被布局覆盖。示例使用不受这些约束的数值属性，不修改布局引擎。
- 时间定位只处理现有数值属性，不播放音频、粒子、骨骼动画，也不触发业务事件。蓝色方块独立上下伸缩不属于时间轴的一部分。

# 多个 Scene3D 与二维界面叠放

不依赖外部资源，使用两个独立的 `Scene3D` 展示从后到前的合成：

1. 底层 Scene3D：不透明背景、地面和旋转的蓝绿色方块。
2. 中层二维 Sprite：米色不透明面板和文字，覆盖底层三维物体。
3. 前景 Scene3D：`backgroundAlpha = 0`，橙色旋转方块覆盖二维面板，空白区域透出面板和底层场景。

两个视口位置、尺寸和相机参数相同，但各自拥有独立的根节点、相机和灯光。橙色方块本身不透明；这里的“透明”指前景视口的背景。跨 Scene3D 的覆盖由二维显示树顺序决定，各场景内部的深度不参与跨视口比较。

核心顺序位于 `Source/GameStage.hx`：先 `addChild(background)`，再 `addChild(panel)`，最后 `addChild(foreground)`。界面顶部的按钮和说明随后加入，便于操作。

## 运行

在本目录执行 `openfl test html5`，需要配置本地 `hxmaker` 和支持 Scene3D 的 `hxmaker-openfl` 后端。

## 手动观察

- 默认画面：米色面板遮住蓝绿色方块，橙色方块显示在面板上方；橙色方块周围仍能看见面板。
- 关闭“前景 3D”：面板完整露出，确认橙色物体来自前景场景。
- 关闭“中层 2D”：底层方块完整露出，确认二维面板可以覆盖三维内容。
- 关闭“透明背景”：前景整个视口变为不透明深色，覆盖底层场景和面板；重新开启后恢复透明合成。
- 关闭“旋转动画”：两个场景中的方块同时停止旋转，方便观察边缘覆盖关系。

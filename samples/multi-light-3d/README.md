# 多光源交互验收示例

启动类 `Main` 继承 `hx.core.HxmakerApplication`，通过 `init(GameStage, 1100, 760)` 初始化业务舞台。场景完全使用程序化网格，无需下载模型或贴图。

## 当前范围

- 方向光、有限范围点光、带平滑内外锥的聚光共同参与 Lambert 漫反射。
- 同时计算最多 4 盏灯。主方向光优先，其他灯按显式注册顺序选择；隐藏、已销毁、移出场景、强度为零的灯不占名额。
- 只有 `scene.light` 指定的主方向光生成阴影，阴影不压暗其他灯光和环境光。
- Shader 编译失败时先降低多纹理槽位，再逐步降低灯光上限；实际灯光和跳过数量显示在底部。若最低配置仍无法编译，则保留原有错误上报。
- 镜头复用 `OrbitCameraController3D` 和 `Scene3DInput`：视口内左键或单指拖动环绕、滚轮缩放，支持拉近、拉远与复位按钮；距离限制为 5～40，俯仰角限制为 5°～85°。
- 本轮不包含材质高光、PBR、环境反射、点光阴影或聚光阴影。

需要同时使用本轮修改后的 `hxmaker` 与相邻 `hxmaker-openfl` 源码。仅更新核心库不会使旧后端显示新增灯光。

## 手动启动

在本目录由开发者执行：

```sh
openfl test html5
```

本次交付没有执行此命令，也没有运行编译、参数检查或渲染测试。

## 交互验收步骤

| 操作 | 预期结果 |
| --- | --- |
| 视口内左键或单指拖动 | 镜头围绕场景中心平滑旋转，俯仰角不会翻转或钻入地面 |
| 在视口内滚动滚轮，或点击拉近／拉远 | 镜头平滑缩放，观察距离保持在 5～40 内 |
| 点击镜头复位 | 立即恢复初始位置与观察中心，取消正在进行的拖动 |
| 操作顶部灯光按钮 | 只改变对应灯光，不触发镜头拖动 |
| 关闭移动和自动重绘后操作镜头 | 镜头仍可操作，相机变换触发重绘 |
| 初始状态 | 红蓝点光和暖色聚光叠加在灰色方块、地面上，参与灯光为 4 |
| 暂停移动后，依次开关红点光、蓝点光 | 对应颜色贡献出现或消失，其他灯继续照明 |
| 点光范围从 8 改为 4 | 红蓝点光照明范围缩小，边缘平滑衰减 |
| 关闭其他灯，仅保留聚光；切换外锥半角 | 地面光斑范围变化，内外锥之间为柔和过渡 |
| 开关主方向光阴影 | 方块投影变化，点光和聚光贡献仍然保留 |
| 开启第五灯 | 默认前四灯全部有效时，第五灯被跳过；跳过数量为 1 |
| 保持第五灯开启，关闭红点光 | 绿色点光进入有效灯光集合，跳过数量归零 |
| 开关蓝光父节点 | 蓝点光及其标记同时隐藏或恢复 |
| 关闭移动，再关闭自动重绘，然后切换范围、锥角、第五灯 | 直接属性修改仍触发重新绘制 |
| 点击“运行参数检查” | 显示“参数检查通过”；失败时按钮显示错误原因 |

参数检查仅在用户点击按钮时执行，覆盖重复注册、集合副本、父节点变换、隐藏、零强度、跨场景注册、非法范围与锥角、负强度、移出场景和销毁。

## 接入方式

```haxe
var point = new hx.light.PointLight3D(0xff8040, 2, 8);
scene.root.addChild(point);
point.setPosition(0, 2, 0);
scene.addLight(point);

var spot = new hx.light.SpotLight3D(0xffffff, 3, 12);
scene.root.addChild(spot);
spot.setPosition(0, 6, 0);
spot.direction = new hx.geom.Vector3D(0, -1, 0);
spot.innerAngle = 18;
spot.outerAngle = 30;
scene.addLight(spot);
```

`range` 是世界空间半径，不随节点缩放改变。距离衰减为 `max(1-distance/range, 0)²`，强度为艺术调节参数。聚光角度是半角，单位为度，要求 `0 ≤ innerAngle < outerAngle < 90`。

灯光必须先加入当前场景再注册。`removeLight` 只取消注册，不销毁节点；兼容入口 `scene.light` 需单独清空。`lights` 返回显式注册列表的副本；`getActiveLights()` 返回筛选后的全部有效灯光，后端按上限截取，不自动进行距离或重要性排序。

# 基础 3D 示例

此示例使用程序生成的棋盘格贴图，不需要下载外部模型或图片。

依赖当前开发版本的 hxmaker 和 hxmaker-openfl。示例配置列出的 haxelib 必须已安装，并指向包含本次实现的源码。

经用户允许执行验证后，可在本目录使用：

```bash
openfl test project.xml html5
```

当前未执行编译或运行验证；命令仅供后续手动验证。

示例包含十二个共享几何的模型、十二张独立贴图、一个地面、一个透明模型及覆盖在场景上方的文字。点击标题可切换三维多纹理合批；点击模型可查看拾取结果。不同设备的槽位数可能不同，实际批次数以界面显示为准。

重点观察：模型深度遮挡、相机运动、父子节点旋转、纹理编号正确性、透明物体和三维前后二维文字的显示情况。多纹理模式应在材质与容量兼容时减少批次数，不能预设所有设备上都是一次绘制。

使用说明见 [基础 3D 框架使用说明](../../docs/基础3D框架使用说明.md)。

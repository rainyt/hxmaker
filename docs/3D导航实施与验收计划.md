# 3D 导航实施与验收计划

日期：2026-10-17。用户已授权本轮编译、运行与测试；按独立逻辑步骤提交 Git。

## 交付范围

1. 独立 `hx.navigation3d` 路点图与 A* 搜索：有向边、通行开关、最短路、不可达与搜索预算反馈。
2. 借用 `CharacterController3D` 的路径跟随：显式更新、暂停与停止、到达判定、阻挡反馈、图变更后重规划。
3. 标准 hxmaker 示例：通过 Assets 加载贴图动画角色，演示绕墙、动态门、楼梯、坡道及不可达目标；显示路径并可销毁重进。
4. 新增公开 API 中文文档和格式化；覆盖数值断言、HTML5 构建、浏览器运行和资源释放。

## 边界与不变量

- 路点与连接由项目显式配置，连接代表已经为相应角色验证过的可走路线，不自动生成 NavMesh。
- 世界坐标以角色脚底为基准。高度参与到达判断，避免不同楼层被误判到达。
- 碰撞、重力与跨步继续由角色控制器处理。每帧仅推进一次位移、一次动画和一次相机更新。
- 保留左键拖动镜头、轻点选目标的既有输入，不改帧调度与多纹理合批规则。
- 导航对象不接管模型、控制器、碰撞世界或 Assets 的生命周期。

## 验收要点

- 同起终点、单向路、零成本连接、断图、禁用节点与边、搜索预算及路径快照。
- 正常跟随、转角、暂停恢复、停止、目标重设、高度不匹配、物理阻挡与图修改。
- 绕墙、门开关后改道、楼梯和坡道上下行、封闭目标失败反馈。
- 示例资源加载成功，动画随实际位移切换，反复重进时监听与资源引用正确释放。

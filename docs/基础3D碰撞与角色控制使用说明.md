## 范围与分工

新增 hx.collision3d：BoxCollider3D、CollisionWorld3D、CollisionHit3D、CharacterMoveResult3D，以及内部距离计算工具 CollisionMath3D。hx.controls3d 新增 CharacterController3D。

首版支持世界轴对齐箱体代理、竖直胶囊／球体的重叠与连续扫掠、代理射线、层位掩码、阻挡滑动、初始重叠推出、落地、重力和简单起跳。整个实现不依赖 OpenFL、Lime 或渲染器，不新增全局更新器，不修改帧调度、多纹理合批和现有 Scene3DInput。

碰撞体由业务显式创建，不自动把渲染模型或骨骼网格作为碰撞网格。渲染可见性不影响碰撞；节点销毁、代理禁用或注销后不再参与查询。可绑定节点并在每次查询中读取其最新变换，但不自动携带站在移动平台上的角色。

箱形代理若有旋转，按八角变换得到保守世界 AABB，旋转后的空角仍会阻挡。竖直胶囊的 radius 和 height 使用世界单位，height 包含两端半球；绑定模型的旋转和缩放不会改变胶囊方向与尺寸。

本版没有三角形网格碰撞、角色之间的胶囊碰撞、动态刚体、碰撞事件、台阶攀爬、通用斜坡或导航避障。isTrigger 只影响查询过滤，不派发进入／离开事件。角色可能持续尝试前往墙后的目标，需要业务自行决定何时放弃或寻路。

## 注册箱体与查询

```haxe
var world = new hx.collision3d.CollisionWorld3D();
var wall = new hx.collision3d.BoxCollider3D(0.2, 3, 8, wallMesh);
wall.name = "墙壁";
wall.layer = 1; // 位掩码，2 为第二层，3 同时包含两层。
world.add(wall);

var hit = world.sweepCapsule(
    new hx.geom.Vector3D(-3, 1, 0), 0.5, 2,
    new hx.geom.Vector3D(10, 0, 0), 1);
if (hit != null) trace(hit.fraction);
```

BoxCollider3D 的 size 和 offset 是绑定节点的局部尺寸／中心偏移；node 为 null 时即为世界值。半径必须为正，高度至少为直径，箱尺寸必须为正，参与计算的数值必须有限；超出计算数值范围也明确报错。

| 查询 | 说明 |
| --- | --- |
| raycast(ray, maxDistance=null, mask=-1, includeTriggers=false) | 最近代理命中，距离为世界距离，不受相机裁剪限制 |
| overlapSphere(center, radius, mask=-1, includeTriggers=false) | 返回全部球体接触，接触时 penetration 可为零 |
| overlapCapsule(center, radius, height, mask=-1, includeTriggers=false) | center 是世界中心，不是脚底 |
| sweepSphere(center, radius, displacement, mask=-1, includeTriggers=false, skin=1e-5) | 整段球体位移查询 |
| sweepCapsule(center, radius, height, displacement, mask=-1, includeTriggers=false, skin=1e-5) | 整段竖直胶囊位移查询 |

mask=-1 包含全部层，mask=0 不包含任何层。默认排除 isTrigger=true 的代理，控制器也不被此类代理阻挡。当前使用线性候选列表和扫掠 AABB 初筛，适用于初版小场景，没有空间树加速。

CollisionHit3D 包含借用 collider、世界 point／normal、世界 distance、扫掠 fraction、penetration 和 conservative。normal 指向箱体外侧；射线起点在箱内时 distance=0，point 为射线起点。fraction 仅用于扫掠，表示沿原位移完成的比例。

胶囊中心线沿世界 Y 轴，其到 AABB 的距离可转为球心到沿 Y 扩展后的箱体距离，再保留球体圆角。扫掠沿分离面保守推进，每个候选最多 64 次迭代；达到上限时返回 conservative=true 的保守阻挡。零位移扫掠只报告初始穿插，接触与切向运动使用重叠查询或非零扫掠。查询方法不推进时间或节点。

## 角色控制器

```haxe
var control = new hx.controls3d.CharacterController3D(world, model, 0.35, 1.9);
control.collisionMask = 3;
control.teleport(new hx.geom.Vector3D(-5, 0, 0));

// 在既有业务更新里执行一次；横向速度的 Y 必须为零。
var result = control.update(dt, new hx.geom.Vector3D(3, 0, 0));
if (result.grounded) trace("已落地");
```

position 是世界脚底位置的副本。构造时读取节点世界位置，此后控制器拥有平移；使用 teleport 改变位置，不同时直接写节点的平移。节点朝向、动画和尺度仍由业务管理。控制器将世界脚底换算为父节点局部坐标，支持可逆的旋转、非均匀和负缩放父变换；不可逆父矩阵在修改运动状态前报错。

| 接口或设置 | 契约 |
| --- | --- |
| update(dt, horizontalVelocity) | dt 非负，速度单位为世界单位／秒；只接受 Y=0，积分重力后执行一次 move |
| move(displacement) | 世界位移，不自动推进重力；整段扫掠并沿接触面滑动 |
| teleport(position) | 直接设置脚底并清除落地／垂直速度；不扫描路径，下次 move 处理初始重叠 |
| jump(speed) | 仅 grounded 时起跳，返回是否成功；不自动调用更新 |
| skinWidth=0.002 | 正数且小于半径，避免接触数值误差 |
| groundSnapDistance=0.12 | 下移／水平运动后的向下贴地范围；上升时不吸回地面 |
| minGroundNormalY=0.7 | 支撑面法线阈值，避免墙面被当作地面 |
| gravity=-20 / maxFallSpeed=30 | 向下重力与终端速度；每次 update 按 dt 积分，不修改引擎帧率 |
| maxSlideIterations=8 / maxRecoveryIterations=12 | 运动与推出预算，允许 1～64 |

update 使用分段积分在达到最大下落速度后保持终端速度；对整段位移进行连续扫掠，不通过只检查终点避免穿墙。大 dt 仍只有有限次滑动响应，不承诺与任意时间切分得到相同运动轨迹。低于阈值的微小剩余位移停止处理。

CharacterMoveResult3D 返回实际 displacement、contacts、grounded、hitCeiling、blocked、stuck 和 iterationLimited。blocked 表示发生阻挡，包含地面，不专指墙壁。初始穿插逐次按最深接触推出；推出预算耗尽后 stuck=true，停止请求运动，保留已经完成的推出。滑动预算耗尽则丢弃尚未确认的剩余位移，并设置 iterationLimited=true。接触可能重复，不将 contacts 数量当作唯一物体数量。

示例按实际水平位移决定 Idle／Walk，所以目标被墙挡住时会待机；动画和控制器每业务帧分别更新一次，然后更新相机。胶囊是角色主体代理，不会逐帧包裹摆动手臂或附件。

## 资源所有权

world.add 借用代理，一个代理同时只能注册到一个世界。remove／clear／world.dispose 只注销，不销毁代理或绑定节点。BoxCollider3D.dispose 自动注销并清除节点引用，不销毁节点。CharacterController3D.dispose 解除引用，不销毁世界和角色。

示例退出顺序：解除输入与键盘监听 → 销毁控制器与碰撞代理 → 销毁世界 → 销毁模型及显示树 → 释放自建几何／材质 → 清理 Assets。取消加载不保证原生请求已结束，迟到结果收到后再次 clean，不创建已退出场景的模型。

# PBR 材质对比

展示 Lambert、PBR 非金属和 PBR 金属三类材质，以及粗糙度对高光的影响。

镜头复用 `OrbitCameraController3D` 和 `Scene3DInput`：

- 视口内按住鼠标左键或单指拖动，旋转观察方向；滚轮缩放。
- “拉近镜头”“拉远镜头”可用于鼠标或触屏缩放。
- “镜头复位”恢复初始位置，并停止自动环绕。
- “自动环绕”切换自动运镜，开始拖动、滚轮或按钮缩放后自动关闭；再次开启时从当前角度继续。
- 距离限制为 4～30，俯仰角限制为 5°～80°，避免镜头穿入地面；不包含双指缩放。

DrawCall 对比按钮：

- “统一 PBR 参数”：10 个 PBR 球均设为金属度 0、粗糙度 0.5，保留各自独立材质实例。
- “恢复原始参数”：恢复两行球各自的金属度，以及各列原始粗糙度。
- 切换参数时停止自动环绕，保持观察位置。底部分别显示主场景、阴影和二维合成批次。
- 全部球体可见、无额外拆批时，主场景预计从 11 批降到 2 批，恢复后回到 11 批；这是源码推算，尚未实测。阴影缓存命中时阴影批次可能为 0，全局 FPS 中的 DrawCall 还可能包含文字等二维内容。

需要使用本轮 hxmaker 与 hxmaker-openfl 开发源码。入口继承 `HxmakerApplication`；示例不依赖外部资源。

首版使用直接光照与简化环境漫反射，尚无 IBL 环境反射、PBR 数据贴图或法线贴图。纯金属的暗部会偏暗。

本示例尚未编译或运行。详细接口、限制和待验证项目见[使用说明](../../../docs/PBR材质使用说明.md)。

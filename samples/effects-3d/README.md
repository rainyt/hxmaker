# 三维特效示例

展示 CPU 粒子火球拖烟、延迟命中爆炸、四帧图集动画、广告牌、加法光圈，以及第二阶段的弹道拖尾、双端刀光和遮罩流光溶解。第三阶段增加贴地软粒子烟雾与 Bloom 泛光。所有贴图由示例生成，无外部素材。

`Source/Main.hx` 统一继承 `hx.core.HxmakerApplication`，通过 `init(Game, 960, 640)` 启动；`Source/Game.hx` 继承 `hx.display.Stage`，在 `onStageInit()` 中创建特效场景与界面。

先确保 `hxmaker` 与 `hxmaker-openfl` 都使用本次修改后的本地版本。在此目录可通过以下命令启动 HTML5 示例：

```sh
openfl test html5
```

- 鼠标左键或单指拖动视口：环绕旋转镜头，可转到侧面和下方观察。
- 鼠标滚轮：拉近／拉远，距离限制为 3 至 20。
- 点击“软粒子”：开关烟雾与地面／方块交界淡出。
- 点击“泛光”：开关整个三维视口的亮部泛光。
- 点击标题：暂停／恢复特效；暂停时仍可旋转和缩放镜头。
- 轻点视口：切换背景透明度；拖动结束不会触发背景切换。

底部显示活跃粒子数量、轨迹截面数量、主场景／深度／泛光绘制批次、功能启用或回退原因，以及镜头操作提示。动态材质示例的主贴图和噪声来自图集左半区域，正常效果中不应出现图集右半区域的洋红色。

前两个阶段已由用户反馈测试通过；第三阶段尚未编译或运行验收。详细接口与待验收项见 [第一阶段说明](../../docs/3D特效第一阶段使用说明.md)、[第二阶段说明](../../docs/3D特效第二阶段使用说明.md) 和 [第三阶段说明](../../docs/3D特效第三阶段使用说明.md)。

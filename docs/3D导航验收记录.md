## 回归发现并修复的问题

- 二维坐标正逆变换：计算 Y 时误用已经变换的 X，旋转或错切视口会偏移。改为始终使用原始输入，补充正逆变换和三维拾取断言，独立提交。
- 导航示例 UI 焦点：点击自身按钮也会触发视口失焦，原来的暂停监听导致门按钮误暂停角色。调整为窗口停用时自动暂停，保留内部 UI 操作，真实键鼠回归通过。

现有左键拖镜头和抬起确认选择保持原有交互；帧调度、多纹理合批、后端接口和 GL 状态保护均沿用既有实现。本轮未修改 hxmaker-openfl。

## 复现方式

仓库根运行：

```bash
arch -x86_64 haxe test/navigation-graph.hxml
arch -x86_64 haxe vscode-openfl.hxml
```

分别进入以下示例目录执行构建：

| 示例目录 | 命令 |
| --- | --- |
| samples/terrain-character | `arch -x86_64 lime build html5 -D hxmaker_terrain_checks` |
| samples/textured-character | `arch -x86_64 lime build html5 -D hxmaker_character_checks` |
| samples/camera-interaction | `arch -x86_64 lime build html5 -D hxmaker_camera_checks` |
| samples/navigation-character | `arch -x86_64 lime build html5 -D hxmaker_navigation_checks` |

从仓库根启动 `python3 -m http.server 8731 --bind 127.0.0.1`。已安装 Playwright 时运行 `node test/tools/run-3d-browser.cjs`。可用环境变量指定：

- `PLAYWRIGHT_MODULE`：Playwright 模块路径；默认从 Node 模块搜索路径解析。
- `CHROME_PATH`：本机 Chrome 可执行文件；省略时使用 Playwright 自带 Chromium。
- `HXMAKER_TEST_BASE`：静态服务地址，默认 `http://127.0.0.1:8731`。
- `HXMAKER_TEST_REPORT`：可选 JSON 报告输出位置。
- `HXMAKER_TEST_SCREENSHOT`：导航操作截图输出位置，默认 `/tmp/hxmaker-navigation.png`。

普通示例使用 `arch -x86_64 lime test html5`。普通构建不运行数值断言，批量回归前需按上表重新构建验收宏版本。

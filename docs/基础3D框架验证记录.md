# 基础 3D 框架验证记录

日期：2026-10-16。

## 环境与命令

- 本地 macOS，x86_64 模式运行 Lime 工具链。
- OpenFL 9.2.8 与 Lime 8.0.2 开发源码。
- 示例目录：`samples/basic-3d`。
- 命令：`arch -x86_64 lime test html5`。
- 编译产物：`Export/html5/bin/Basic3D.js`；通过本地端口 3000 访问。
- 浏览器：Codex 内置浏览器，使用实际 GPU 绘制页面和手动点击交互确认结果。

## 测试中修复的问题

1. RenderStateGuard3D 的顶点属性启用状态混用了 Bool 和 Int 比较，导致编译错误。改为按 Bool 恢复。
2. 示例在 OpenFL 后面重复声明 Lime，导致生成的 ApplicationMain 使用 Lime Application 模板，无法接受 OpenFL Sprite 入口。去掉重复的 Lime 声明后，重新生成了正确的 OpenFL 入口，编译通过。
3. 初次启动 HTML5 服务受到沙箱监听端口限制。允许本地测试服务启动后，浏览器正常加载。此项属于运行权限问题，没有修改引擎代码。

| --- | --- |
| HTML5 编译 | 通过，生成完整 JavaScript 和页面 |

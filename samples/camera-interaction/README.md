## 操作

- 主视口左键点击角色或手持附件：切换选中角色，地面黄色标记指示当前选择。
- 主视口左键点击空白地面：抬起确认轻点后设置移动目标，使用按下时固定的相机射线；红色标记指示目的地，Idle/Walk 自动过渡。
- 左键拖动超过 5 个舞台逻辑像素：旋转相机，释放后不触发选择；滚轮缩放。触摸同样为轻点选择／移动和单指拖动旋转。
- **相机**：在固定中心环绕与角色跟随间切换；**下一个角色**切换跟随目标。
- **拉近 / 拉远 / 重新取景**：也可通过按钮操作镜头。
- **自动移动**：所选角色沿四个地面目标移动，便于观察平滑跟随。
- **视口变换**：改变主视口的二维缩放和旋转，检查选中位置仍对应实际画面。
- 右侧视口单独拖动、缩放和选取，只更新自己的状态，不控制主角色。
- 主视口上方的二维 UI 接收并消费按下、移动和抬起；点击只增加 UI 计数，不应触发相机操作或地面移动。
- 从主视口开始拖动，经过二维 UI 或进入右侧视口后释放，应结束原拖动且不触发另一视口选择。
- **暂停／继续**只冻结角色移动和动画，相机仍可操作；**取消当前拖动**解除捕获。
- **多纹理 / 阴影**供画面对照；两个视口分别显示批次数，不承诺跨视口一个批次。
- **重新加载资源**和底部**销毁并重新进入场景**覆盖资源和输入生命周期。加载期间可重新进入，迟到结果清理引用。

移动使用无碰撞的运动学位移，目标范围为 X/Z ±10。相机没有碰撞避障；示例将俯仰下限设为 5 度。发生窗口级输入缺失时，可显式取消拖动；触摸采用单指旋转，尚无双指缩放。

## 更新与资源所有权

Scene.onUpdate 按“位移与业务动作选择 → 每模型一次动画更新 → 活动相机更新”执行，不修改引擎帧调度。两个视口的模型实例独立，只有源贴图通过 Assets 共享。

场景退出时先销毁输入适配，解除舞台捕获，再销毁模型、控制器和三维视口；外部创建的几何与材质在网格解除引用后释放，最后清理 Assets。重新加载同样先释放旧实例及附件几何。

## 可选断言

仅在用户需要时执行：

```bash
arch -x86_64 lime test html5 -D hxmaker_camera_checks
```

检查相机父变换、距离与角度边界、固定目标下平滑 dt 切分、跟随、射线近远裁剪与最大距离、负缩放、网格过滤、挂点所属模型、二维 UI 和双视口输入隔离、触摸 ID、取消与销毁。成功时输出 `HXMAKER_CAMERA_INTERACTION_CHECKS PASS`。

本次追加相机平滑中拾取快照保持、射线与舞台坐标一致、左键拖动旋转及释放后停止接收旋转指令的断言，尚未运行。

可选断言尚无独立执行记录；模拟事件不证明具体浏览器或设备的原生事件转发均已通过。后续跨平台与边界回归仍需分别记录。

完整接口见[相机控制与交互使用说明](../../docs/3D相机控制与交互使用说明.md)。

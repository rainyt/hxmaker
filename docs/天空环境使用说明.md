# 天空环境使用说明

天空背景由 `Scene3D.skybox` 控制，PBR 环境光照由 `Scene3D.environment` 控制。两者可以独立使用，也可以用 `SkyEnvironment3D` 统一旋转。需要配套包含 `SkyboxPass3D` 的 hxmaker-openfl 开发版本。

## 资源生成

```bash
# 同源生成高清天空和低分辨率 IBL，输入也支持 PNG/JPEG 全景
python3 tools/bake-ibl.py --input studio.hdr --output assets/sky --sky-width 2048

# 只输出天空；不执行 IBL 卷积
python3 tools/bake-ibl.py --input panorama.jpg --output assets/sky --sky-width 2048 --sky-only

# 六面资源转天空及 IBL
python3 tools/bake-ibl.py --cube-dir faces --output assets/sky --sky-width 2048

# 不指定输入时使用无第三方依赖的程序摄影棚
python3 tools/bake-ibl.py --output assets/sky --sky-width 512 --width 32 --levels 4 --samples 32
```

全景输入要求宽高比为 2:1。六面目录使用 `px/nx/py/ny/pz/nz` 文件名，每面恰好一个 `.png`、`.jpg`、`.jpeg` 或 `.hdr` 文件，要求同尺寸正方形，单面不超过 4096。普通图片读取需要 Pillow；HDR 全景读取和程序摄影棚不依赖 Pillow。

六面按左上角开始读取，使用以下方向约定。`u/v` 为图中从左到右、从上到下的 -1～1 坐标；方向归一化后用于采样：

| 面 | 方向 |
|---|---|
| px | (1, -v, -u) |
| nx | (-1, -v, u) |
| py | (u, 1, v) |
| ny | (u, -1, -v) |
| pz | (u, -v, 1) |
| nz | (-u, -v, -1) |

转换在滤波跨过面边界时采样邻面。输入素材自身的朝向和接边内容仍须正确。

`--sky-width` 为有效天空宽度，支持 16～4096 的偶数，默认 0 保持旧工具行为。天空分辨率与 `--width` 指定的 IBL 层分辨率互不影响。天空 PNG 实际尺寸为 `(width+2) × (width/2+2)`，包含左右周期边框和上下夹边。工具逐行处理高清输出，避免保存整张天空的 Python 浮点元组。

输出 `sky.png/sky.json`，以及原有的 `environment.png/environment.json`；旧 IBL 格式保持 `hxmaker-ibl-1`。天空使用新格式 `hxmaker-sky-1`，编码为 `linear-rgb-range`。不得对生成图片执行 sRGB 重编码、调色、透明化或有损压缩。8 位范围编码保留大于一的辐射范围，但极端 HDR 明暗比会丢失暗部精度。

## 加载与联动

```haxe
var assets = new hx.assets.Assets();
assets.loadBitmapData("assets/sky/sky.png");
assets.loadJson("assets/sky/sky.json");
assets.loadBitmapData("assets/sky/environment.png");
assets.loadJson("assets/sky/environment.json");
assets.onComplete(_ -> {
    var texture = hx.render3d.SkyboxTexture3D.fromData(
        assets.getBitmapData("sky"), assets.getObject("sky"));
    var source = hx.light.Environment3D.fromData(
        assets.getBitmapData("environment"), assets.getObject("environment"));
    var settings = new hx.light.SkyEnvironment3D(texture, source);
    settings.rotation = 30;
    settings.skybox.toneMapping = true;
    settings.skybox.exposure = 1;
    settings.environment.intensity = 1;
    settings.applyTo(scene);
    // 将 assets、texture、source、settings 保存到业务对象，使用期间保持存活。
});
assets.start();
```

联动对象复制源环境参数，并借用相同 IBL 图片；后续修改源对象的参数不改变复制后的配置。一个联动对象只绑定一个场景，再次 `applyTo` 会先解除旧绑定。多个场景分别创建联动对象，共享天空资源和 IBL 图片，即可获得独立的旋转、曝光和强度。直接修改 `settings.skybox.rotation` 或 `settings.environment.rotation` 可以有意取消同步；之后设置 `settings.rotation` 会再次统一两者。

全景使用世界 Y 向上，`u = atan2(z,x)/(2π)+0.5`，`v = acos(y)/π`，与 IBL 相同。`rotation` 沿用 `Environment3D` 的采样旋转约定，单位为度。

## 独立天空与普通图片

```haxe
// 不需要 IBL，不需要预处理；输入须为不透明的 2:1 sRGB 整图。
var texture = hx.render3d.SkyboxTexture3D.fromPanorama(bitmap);
scene.skybox = new hx.render3d.Skybox3D(texture);

// 复用旧环境图集的第零层，适合低清预览。
var preview = hx.render3d.SkyboxTexture3D.fromEnvironment(environment);
scene.skybox = new hx.render3d.Skybox3D(preview);
scene.skybox.toneMapping = true;
```

普通图片在着色器中执行周期双线性采样，先解码 sRGB 再插值，兼容非二次幂图片及 OpenFL 上传填充。预处理天空与 IBL 则利用边框进行硬件线性采样。所有输入都要求完整图片，拒绝图集裁片和带裁边还原信息的帧。天空忽略纹理 Alpha，普通输入请使用不透明图片。

## 参数和显示行为

| 参数 | 默认值 | 行为 |
|---|---|---|
| `scene.skybox` | null | 未配置时使用原有背景 |
| `skybox.enabled` | true | 关闭后恢复原有背景 |
| `skybox.rotation` | 0 | 绕世界 Y 轴采样旋转 |
| `skybox.intensity` | 1 | 线性亮度倍率，0 表示黑色天空 |
| `skybox.exposure` | 1 | 色调映射前线性倍率 |
| `skybox.toneMapping` | false | 开启 Reinhard 映射，HDR 通常应开启 |

强度和曝光必须为 0～1000000 的有限值；辐射范围以及乘上亮度和曝光后的最大范围不得超过 1e30。普通图片默认关闭色调映射以保持原貌；预处理资源应由业务显式选择映射策略。

天空通过一个全屏三角形先绘制到当前三维离屏目标，不增加离屏目标，不占用模型批次的纹理预算。它随相机旋转、视角和视口比例变化，不随相机平移，不受近远裁剪面影响。天空不加入节点树，不参与拾取、视锥裁剪、碰撞、阴影或软粒子深度预绘制。

天空输出不透明颜色；`backgroundAlpha` 只影响没有绘制天空时的清屏背景。整体透明度沿用 `Scene3D.alpha` 的二维合成。不透明物体遮挡天空，透明物体混合天空。天空在主场景 Bloom 之前绘制，亮部会参与 Bloom。

当前仍为 LDR 颜色目标，天空自身执行色调映射和显示编码。这支持 HDR 源资源，但不是浮点 HDR 渲染或 HDR Bloom。没有动态天气、大气散射、实时环境捕获或动态物体反射。

## 重绘、共享与释放

场景和后端都检测天空参数与资源版本，包括 `autoRender=false` 的情况。更新共享天空图片后调用 `texture.invalidate()`；它只更新天空版本。更新 IBL 图片时对使用者持有的 `Environment3D` 调用 `invalidate()`。需要立即刷新时显式调用对应场景的 `requestRender()`。

推荐释放顺序：

1. `settings.dispose()` 解除场景绑定并销毁该联动对象持有的天空和 IBL 配置。
2. 从其他使用者解除共享资源，再调用 `texture.dispose()`、`source.dispose()`。
3. 最后调用持有图片的 `assets.clean()`。

单独使用时，先将 `scene.skybox` 设为 null，再销毁天空配置和不再共享的资源。销毁场景只清除天空引用，不销毁借用配置、资源或图片。联动对象解绑时仅清除仍属于自身的引用，保留业务后来替换的配置。

GPU 程序和顶点缓冲由后端释放；上下文丢失时丢弃旧句柄，恢复后重建，并沿用 OpenFL 图片上传协议。

## 诊断与验证

- `scene.stats.skyboxDrawCalls`：最近一次重绘的天空提交数，启用时为 1；不计入网格 `drawCalls/triangles`。
- `scene.stats.skyboxTextureBytes`：按上传尺寸估算的借用 RGBA 纹理字节数，不是新增离屏显存，也不能将多个共享视口的该值直接相加作为独占显存。
- `scene.stats.skyboxStatus`：关闭、启用、无相机或具体回退原因。

超过设备纹理尺寸时保留原背景；缺少片元高精度时，超过 1024 尺寸、60000 辐射范围或亮度计算范围的资源回退为原背景。天空程序创建失败会记录原因，并在下次上下文重建时重试。布局错误、已释放资源和无效业务参数明确抛错，避免掩盖资源问题。

独立示例位于 `samples/3d/skybox`。资源工具回归入口为 `python3 test/tools/test_skybox_bake.py`。浏览器验收先在示例目录构建 `arch -x86_64 lime build html5 -D hxmaker_skybox_checks`，从仓库根启动静态服务后，运行 `test/tools/run-skybox-browser.cjs`，详见示例 README。验收宏关闭时，不包含 GPU 读回和浏览器命令入口。

## 操作与预期

WASD／方向键按世界 X/Z 移动，空格起跳，Esc 停止目标移动。左键拖动转镜头，滚轮缩放，轻点可见地面／坡面设置目标；二维按钮不会穿透。按钮指定起点和目标后，实际位移仍由角色控制器产生。

- **上台阶**：左侧四级楼梯，每级 0.4，高度总计 1.6；跨步配置为 0.45，应走上平台。
- **下台阶**：从平台走下，向下贴地范围为 0.45，应逐级回到地面。
- **跨步开／关**：关闭后重新点击“上台阶”，首级高于半径 0.35，应被挡住；开启后再比较。
- **矮顶棚**：台阶本身高度合格，但头顶空间不足，应停住，不能穿过顶棚。
- **过高台阶**：0.85 高障碍超过配置，应阻挡。
- **上缓坡／下缓坡**：绿色坡道约 20°，应能往返，途中按 Esc 停止目标、松开方向键后可观察站立是否稳定。
- **陡坡限制**：橙色坡道约 58°。45° 上限时应被限制；切成 65° 并重新开始，应能上行。
- **旋转坡道**：蓝色坡道旋转 90°，沿世界 +X 升高，应与绿色坡道使用同一套查询逻辑。
- **销毁并重新进入场景**：重新加载角色，检查旧输入与碰撞代理释放。HXMAKER_TERRAIN_RELEASE 日志应显示世界已销毁、注册数和自建几何／材质引用为零。

状态行显示 grounded、垂直速度、stepped、slopeLimited 和 stuck；支撑法线 Y 显示在下一行。跨步标记只描述当前更新，可能很短暂，不会自动给出画面通过结论。机器人按 0.6 缩放，胶囊半径 0.35、总高 1.9，手臂与附件不逐个参与碰撞。

坡道使用封闭楔形代理的真实斜面，不把其整个 AABB 作为实体。本版不包含任意网格地形、动态刚体、自动携带的移动平台、导航或视觉脚步平滑。

## 衔接修复

新增回归复现了以下问题：父节点 x 从10变为30，子自定义显示对象 x为7；坐标查询已经返回世界位置37，后端原生对象仍停在旧位置17。

原因是 f1d8533 删除了 Render 对 __consumeWorldTransformChanged 的消费。世界矩阵缓存已更新，但 CustomDisplayObject、九宫格与 repeat 依赖的渲染失效标记没有更新。

76c0a9f 恢复原有通知消费，调用 __setRenderTransformDirty 只使渲染缓存失效，不把刚计算好的世界矩阵再次标脏。静止节点的变化通知只消费一次，保留按需计算和缓冲增量构建。

本次没有扩大遮罩、滤镜、离屏等特殊作用域的缓存范围，没有修改 OpenFL 或 Lime。原生平台、小游戏真机与 Spine 实际动画仍未单独验证。历史CPU基准不是整帧或GPU提速结论。

# 面包屑导航栏

`BreadcrumbBar` 属于 hxmaker 显示对象体系，继承 `Box`，展示从根到当前位置的单行路径。组件只派发导航请求，由业务层完成跳转并更新实际路径，不扫描文件、不依赖编辑器类型，也不包含刷新按钮。

本文描述本次实现的接口；尚未执行编译、自动化测试或实际界面验证。

## 公开类型与接口

所有公开类型均为独立模块，导入路径如下：

```haxe
import hx.display.BreadcrumbBar;
import hx.display.BreadcrumbItem;
import hx.display.BreadcrumbNavigateEventData;
import hx.display.BreadcrumbBarStyle;
import hx.display.TextFormat;
import hx.events.Event;
```

```haxe
typedef BreadcrumbItem = {
    var label:String;
    var data:Dynamic;
}

typedef BreadcrumbNavigateEventData = {
    var index:Int;
    var item:BreadcrumbItem;
}
```

| 接口 | 说明 |
| --- | --- |
| `new BreadcrumbBar()` | 默认尺寸为 240 × 24 |
| `items:Array<BreadcrumbItem>` | 从根到当前项，最后一项始终为当前位置；默认空数组 |
| `emptyText:String` | 空路径占位文字，默认空字符串 |
| `disabled:Bool` | 默认 `false`；禁用导航、菜单和悬停反馈，同时关闭菜单与提示 |
| `textFormat:TextFormat` | 默认字号 14、文字颜色 `0xcccccc` |
| `appearance:BreadcrumbBarStyle` | 当前项、禁用、悬停和间距外观 |
| `refresh():Void` | 外部字体资源就绪后可主动刷新；常规属性赋值会自动刷新 |
| `BreadcrumbBar.NAVIGATE` | 事件名为 `"breadcrumbNavigate"`，不冒泡，`event.target` 为导航栏 |
| `dispose():Void` | 释放内部显示对象、文字缓存、临时浮层和监听，不销毁业务数据 |

组件保存条目的文字快照和原始 `data` 引用，不修改调用方的数组或条目。读取 `items` 也会返回快照；事件中的 `item` 是独立条目对象，其 `data` 与传入的业务对象保持同一引用。`items = null` 等价于空数组。外部修改数组或条目后，应重新赋值 `items`。

点击祖先项或隐藏菜单中的祖先项时，派发一次导航事件。`index` 始终为完整路径索引。当前项、分隔符、空白和占位文字不派发导航事件；数据赋值、调整尺寸及展开菜单也不触发导航。内部左键点击会被消费，避免父容器重复处理同一次点击。

## 通用业务示例

```haxe
var bar = new BreadcrumbBar();
bar.width = 360;
bar.emptyText = "没有路径";
var project = {id: "project"};
var assets = {id: "assets"};
var textures = {id: "textures"};
bar.items = [
    {label: "项目", data: project},
    {label: "Assets", data: assets},
    {label: "Textures", data: textures}
];
bar.addEventListener(BreadcrumbBar.NAVIGATE, (event:Event) -> {
    var navigation:BreadcrumbNavigateEventData = cast event.data;
    trace(navigation.index, navigation.item.data);
    // 实际跳转成功后，再根据业务状态重新赋值 bar.items。
});
parent.addChild(bar);
```

组件允许在监听回调中立即替换 `items` 或调用 `dispose()`。导航不会自行截断路径，因此跳转失败时仍显示实际当前位置。

## 与 FinderView 组合

```haxe
import hx.display.FinderView;
import hx.display.TreeItem;

var finder = new FinderView();
finder.width = 500;
finder.height = 320;
finder.y = 32;
var bar = new BreadcrumbBar();
bar.width = 500;
bar.emptyText = "未打开项目";
parent.addChild(bar);
parent.addChild(finder);

var projectName = "演示项目";
var projectOpened = true;
var syncPath = () -> {
    if (!projectOpened) {
        bar.items = [];
        return;
    }
    var items:Array<BreadcrumbItem> = [{label: projectName, data: null}];
    for (item in finder.path)
        items.push({label: item.label, data: item});
    bar.items = items;
};
bar.addEventListener(BreadcrumbBar.NAVIGATE, (event:Event) -> {
    var navigation:BreadcrumbNavigateEventData = cast event.data;
    if (navigation.index == 0)
        finder.goToRoot();
    else
        finder.goInto(cast navigation.item.data);
});
finder.addEventListener(FinderView.PATH_CHANGED, _ -> syncPath());
finder.data = [new TreeItem("Assets", [new TreeItem("texture.png")])];
syncPath();
```

项目根项使用 `data: null`，通过索引 0 调用 `goToRoot()`；其他项使用当次 `finder.path` 的真实节点。项目切换及扫描替换数据源后应主动调用 `syncPath()`，即使当前目录仍是根层级。旧扫描节点不能继续复用。导航不触发磁盘重扫、索引更新或文档打开。

## 外观定制与 XML

`textFormat` 和 `appearance` 均按值复制，修改返回值后重新赋值：

```haxe
bar.textFormat = new TextFormat(null, 14, 0xbcbcbc);
var appearance = bar.appearance;
appearance.currentColor = 0xffffff;
appearance.hoverColor = 0x4488cc;
appearance.hoverAlpha = 0.18;
appearance.padding = 4;
appearance.itemPadding = 6;
bar.appearance = appearance;
```

| `appearance` 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `currentColor` | `0xffffff` | 当前项文字颜色，不显示可点击背景 |
| `disabledColor` | `0x777777` | 禁用文字与分隔符颜色 |
| `separatorColor` | `0x888888` | 箭头颜色 |
| `hoverColor` | `0xffffff` | 可导航项和省略入口的悬停背景颜色 |
| `hoverAlpha` | `0.10` | 悬停背景透明度，限制在 0～1 |
| `padding` | `4` | 导航栏左右内边距；极窄时让出内边距 |
| `itemPadding` | `5` | 条目左右内边距 |
| `separatorWidth` | `12` | 条目间箭头所占宽度 |
| `ellipsisWidth` | `24` | 折叠入口宽度，最小 1 |
| `minimumCurrentWidth` | `24` | 折叠时为当前项保留的最小空间，最小 1 |

尺寸和间距会归一化为非负有限值。名称不换行，输入中的换行在导航栏和菜单中显示为空格；事件仍保留原始名称。箭头用 `moveTo()`、`lineTo()` 绘制，不依赖特殊图标字体。

```xml
<Box>
    <BreadcrumbBar id="pathBar" top="4" left="8" right="40" height="24"
        emptyText="未打开项目" disabled="false" fontSize="14" color="0xcccccc"
        currentColor="0xffffff" separatorColor="0x888888"
        hoverColor="0xffffff" hoverAlpha="0.10" itemPadding="5"/>
    <FinderView id="finder" top="32" left="0" right="0" bottom="0"/>
</Box>
```

`UIManager` 已注册类型属性解析，组件带 `@:keep`，现有 `UIBuilder` 可以解析 `<BreadcrumbBar id="...">` 对应的字段类型，无需额外宏映射。XML 支持 `emptyText`、`disabled`、`font`、`fontSize`、`color` 和上表全部外观属性，以及通用位置、尺寸、锚点与 `style="样式名"`。`items` 由代码提供，刷新按钮由业务层单独组合。

当前 hxmaker-openfl 通过共享字形图集渲染文字。字号和颜色按组件格式生效，字体资源按现有全局字体机制配置；单个 `TextFormat.font` 不会独立切换字形图集。本次补齐了 `TextFormat.setTo()` / `clone()` 对 `font` 的复制，未改动后端字体架构。字体资源加载与图集更新完成后可调用 `bar.refresh()` 重新测量。

## 折叠、菜单与生命周期

空间足够时显示全部路径；不足时保留根项和当前项，再尽可能保留靠近当前项的连续祖先。中间隐藏层级用单个省略入口表示。若根项、入口与当前项无法同时容纳，则把根项收入菜单；更窄时只保留省略入口，菜单显示完整路径，当前位置带标记且不可选择。宽度连入口都无法完整显示时，内容与命中均限制在组件边界内，不扩张父布局。

超长的当前项按实际文字宽度截断并添加省略号，悬停显示完整名称。隐藏菜单按原始顺序显示带层级序号的完整路径，选择直接使用捕获的索引，不按名称反查。超出舞台的菜单沿用现有滚动能力，滚轮纵向滚动，Shift＋滚轮横向滚动。

菜单复用 `ContextMenu` 的舞台浮层与关闭逻辑。本次新增：

```haxe
menu.show(owner, stageX, stageY, target);
```

`target` 可省略；坐标为 `owner.stage` 的本地坐标，无需先绑定 `owner.contextMenu`，原有右键绑定方式保持不变。菜单外按下鼠标、Esc、舞台失活、owner 移出舞台时关闭；调用方销毁通过 `show()` 打开的独立 owner 时应主动关闭或销毁菜单。面包屑内部已负责这些清理。

导航栏禁用、数据替换、宽高或样式变化、移出舞台及销毁时关闭菜单和提示。旧条目、旧菜单或已移出舞台对象的回调不能派发旧节点导航。移出后重新加入会重新测量；数据可在加入舞台前设置。临时舞台监听随浮层关闭移除。

本组件使用 `maskRect` 限制绘制和命中，因此会产生现有遮罩渲染开销，不能作为完全自动合批的普通容器看待。

## 示例、兼容性与验证状态

交互示例位于 `samples/breadcrumb-bar/`，同一页面包含通用导航和 `FinderView` 组合，布局由 XML 构建。提供极窄、窄栏、中栏、恢复宽度、禁用、清空和恢复路径操作，并包含中文、英文、混合与重名层级。

需要验证时，可在获得用户后续指示后运行：

```bash
haxe vscode-openfl.hxml
cd samples/breadcrumb-bar
haxelib run openfl test project.xml html5
```

本次没有修改地图编辑器、`FinderView` 或 hxmaker-openfl，没有新增后端版本依赖；应使用与当前 hxmaker 配套的后端源码，继续复用已有文字测量、遮罩与舞台输入能力。

实际完成的检查仅为源码静态阅读与改动核对。按照用户要求，未运行编译、自动化测试、示例启动或视觉验收。以下场景仍需后续验证：

- 空路径、单项、多级目录、同名目录的显示与完整索引、业务引用。
- 中文、英文、空格和混合名称的实际测量、垂直居中与截断提示。
- 连续调整宽度时的折叠、展开、极窄裁剪及相邻控件命中。
- 菜单的舞台边界、滚动、外部点击和 Esc 关闭。
- 导航监听中替换数据或销毁组件，以及旧菜单回调失效。
- 禁用、重复挂载、祖先容器移出舞台和销毁后的资源清理。
- XML 运行时构建、UIBuilder 字段解析、样式及锚点布局。

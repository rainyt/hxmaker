# 距离雾使用说明

距离雾为场景级功能，配置入口是 `Scene3D.fog`，默认关闭。需要同步使用包含距离雾实现的 hxmaker-openfl。

```haxe
scene.fog.enabled = true;
scene.fog.mode = hx.render3d.FogMode3D.LINEAR;
scene.fog.color = 0x809eb8;
scene.fog.start = 12;
scene.fog.end = 65;
scene.fog.maxOpacity = 1;
scene.fog.affectSkybox = false;
```

| 模式 | 雾量 |
|---|---|
| `LINEAR` | `clamp((distance-start)/(end-start), 0, 1)` |
| `EXP` | `1-exp(-density*max(distance-start,0))` |
| `EXP2` | `1-exp(-(density*max(distance-start,0))²)` |

以上结果乘以 `maxOpacity`。距离为相机到片元的世界空间直线距离，在片元着色阶段计算；不是视线 Z 深度，也不是顶点雾。远裁剪面仍决定几何是否被裁剪，雾不会延长相机可见范围。

`start/end` 单位与世界坐标一致，支持 0～1e9；线性模式要求 `end>start`。`density` 为世界距离倒数，支持 0～1e6，零密度关闭指数雾。`maxOpacity` 范围 0～1。错误参数即使处于关闭状态仍会抛错，避免暂时隐藏坏配置。

颜色使用 sRGB RGB 整数。普通、Lambert、PBR、自定义片元材质和特效的最终 LDR 表面颜色转换到线性空间后混入雾色，再进行显示编码与透明预乘。PBR 仍先使用自身色调映射和曝光。雾不改变表面 Alpha，不改变 MASK 裁剪；加法材质按剩余透射率衰减 RGB，不注入雾色，以免远处光效变成彩色亮块。

天空默认保持原貌，推荐将雾色选为接近天空地平线的颜色。`affectSkybox=true` 时将天空视为无限远，按 `maxOpacity` 混合；指数模式零密度时不混合。它不改变 IBL 环境光照或普通清屏背景，不提供高度雾、体积光、局部雾区或真实大气散射。

雾接入现有模型及天空通道，在 Bloom 之前生效，不新增 DrawCall、纹理单元或离屏目标。深度预绘制和阴影通道不应用雾。关闭雾时模型着色器使用不含雾 varying 的原路径。修改雾参数会使静态场景重绘，支持 `autoRender=false`。

`scene.stats.fogStatus` 提供关闭、启用、无相机或回退原因。片元低精度设备无法表示极窄雾区间或极高密度时回退为无雾，而不是上传溢出的参数；归一化线性区间倒数或归一化指数密度大于 10000 时触发回退。其他极端参数与相机范围组合无法表达时明确报错。此实现沿用当前 LDR 渲染管线。

## Blender 制作流程

Blender 作为场景编辑器，hxmaker 负责运行时。此次提供的脚本只增加雾参数面板和 JSON 导出，不改动现有模型、材质或世界节点，也不读取 Blender 原生体积节点。

1. 在 Blender 安装 `tools/blender/hxmaker_distance_fog.py`，或在文本编辑器打开并运行此脚本。
2. 打开“场景属性 → hxmaker 距离雾”，编辑颜色、距离、模式和密度。
3. 保存 `.blend`，参数保存在场景上；使用面板按钮导出 `fog.json`。
4. 模型继续通过 GLB 导出；在运行时加载配套 JSON：

```haxe
assets.loadJson("assets/world/fog.json");
assets.onComplete(_ -> {
    scene.fog.setData(assets.getObject("fog"));
});
```

导出格式为 `hxmaker-fog-1`。`FogSettings3D.fromData()`、`setData()`、`toData()` 提供版本和类型校验；`setData()` 先完整校验，失败时保持原配置。后续统一场景导出器可以直接复用脚本的 `build_fog_data(scene)`，将数据放入场景清单。

距离不隐式应用 Blender 的显示单位换算；它必须与实际导出后模型的世界尺寸一致。Blender 颜色属性使用 sRGB，导出的整数颜色与引擎一致。效果在 hxmaker 中预览，Blender 视口不会自动模拟该着色。此次没有增加 GLB extras 自动读取或完整场景导入器。

脚本的属性注册与导出操作遵循 [Blender 属性 API](https://docs.blender.org/api/current/bpy.props.html) 和 [ExportHelper API](https://docs.blender.org/api/current/bpy_extras.io_utils.html)。

## 示例及验证

独立示例位于 `samples/3d/distance-fog`，展示沿道路排列的远近模型、天空与交互开关。

- `/usr/local/bin/haxe test/fog-settings.hxml`：配置往返、参数错误和颜色解码。
- `Blender --background --factory-startup --python test/tools/test_blender_fog.py`：独立 Blender 实例验证注册、JSON 导出及 .blend 保存恢复。
- 示例目录执行 `arch -x86_64 lime build html5 -D hxmaker_fog_checks` 后，从仓库根启动本地 HTTP 服务，再运行 `test/tools/run-fog-browser.cjs`。

浏览器验收使用软件 WebGL，包含像素断言；不能代表移动设备性能。验收入口仅在宏开启时编译。

实际运行结果及范围见[距离雾与观测站验证记录](距离雾与观测站验证记录-20261019.md)。

# 3D 特效第二阶段使用说明

本阶段新增刀光带、弹道拖尾、动态特效材质，并扩展组合播放器。前两个阶段已由用户反馈测试正确；第三阶段软粒子与泛光尚待验收，见 [第三阶段使用说明](3D特效第三阶段使用说明.md)。

## 能力与文件

| 能力 | 核心类 | 说明 |
| --- | --- | --- |
| 双端刀光 | `hx.display3d.Ribbon3D` | 记录两个世界空间端点，连接相邻截面生成带状网格 |
| 弹道拖尾 | `hx.display3d.Trail3D` | 跟随节点记录中心轨迹，每帧按相机方向重建宽度 |
| 拖尾参数 | `hx.effect3d.TrailSettings3D` | 寿命、采样容量、采样距离、宽度和颜色曲线、瞬移断开 |
| 动态材质 | `hx.material.AnimatedEffectMaterial3D` | UV 滚动与缩放、遮罩、噪声扰动、带边缘颜色的溶解 |
| 组合播放 | `hx.display3d.Effect3D.addRibbon` | 在现有粒子时间轴加入刀光或弹道轨道，指定延迟与采样时间 |

`EffectMaterial3D` 继续作为基础无光照透明材质，不自动启用新 Shader。动态材质继承它，并使用相同的透明混合、深度测试及双面绘制设置。

## 弹道拖尾

```haxe
import hx.display3d.Trail3D;
import hx.effect3d.TrailSettings3D;
import hx.material.BlendMode3D;
import hx.material.EffectMaterial3D;

var config = new TrailSettings3D();
config.width = 0.2;
config.lifetime = 0.4;
config.maxSections = 128;
config.minDistance = 0.02;
config.breakDistance = 3;
var trail = new Trail3D(new EffectMaterial3D(texture, BlendMode3D.ADD), config);
scene.root.addChild(trail);
trail.target = projectile;
trail.play();

// 每帧先更新 projectile 的世界位置与相机，再推进拖尾，时间单位为秒。
trail.update(dt, scene.camera);
```

`target` 为借用节点；为空时记录拖尾自身的世界原点。历史轨迹始终保存在世界空间，不随目标或拖尾父节点移动。宽度为世界单位，乘以截面年龄对应的 `widthOverLife` 曲线。

相机沿轨迹方向观察时，截面宽度退回相机右方向，避免零向量归一化。暂停时设置 `trail.paused = true`，仍调用 `update`，即可冻结轨迹寿命，同时让轨迹响应镜头旋转。

## 双端刀光

```haxe
import hx.display3d.Ribbon3D;
import hx.effect3d.FloatCurve3D;

var config = new hx.effect3d.TrailSettings3D();
config.lifetime = 0.25;
config.widthOverLife = FloatCurve3D.constant(1);
var ribbon = new Ribbon3D(material, config);
scene.root.addChild(ribbon);
ribbon.startNode = bladeBase;
ribbon.endNode = bladeTip;
ribbon.play();

// 先完成角色动画、蒙皮和骨骼挂点更新，再采样武器的两端。
ribbon.update(dt, scene.camera);
```

`startNode`、`endNode` 均为借用节点，必须同时有效；可以使用模型已有的骨骼挂点。刀光截面由两端的真实世界位置决定，镜头旋转不会改变刀光的实际形状。`settings.width` 对截面两端到中点的距离施加倍率，默认一。

不绑定节点时，也可显式调用 `ribbon.addSection(worldStart, worldEnd)`。它记录当前时钟的截面，之后调用 `update(0)` 重建网格；如果先手工记录再传入正的 `dt`，新截面也会经过这段时间的老化。通常优先使用节点绑定，让 `update` 先推进时钟、再记录本帧位置。

## 采样、收尾和资源

- `play()` 清空历史、重置时钟并开始采样。
- `stop()` 停止采样，继续 `update` 直到截面全部到期；`stop(true)` 立即清空。
- `Event.COMPLETE` 在活动轨道停止且历史截面全部移除时派发；立即清空活动轨道也会完成。
- 新截面相对上一截面的最大端点移动距离没有超过 `minDistance` 时不重复采样；静止轨迹会自然消失。
- 位移超过 `breakDistance` 时断开新旧轨迹，避免瞬移产生横跨场景的长条；零表示不限制。
- `maxSections` 限制为 2 至 32767，保持网格顶点数不超过 16 位索引范围。
- `textureRepeatLength = 0` 将整条轨迹映射到零至一；正数按沿轨迹中心累计的世界距离产生重复 UV，需要重复采样材质。
- 颜色、透明度及宽度曲线按截面归一化年龄求值。颜色和透明度限制到零至一，再与材质相乘。
- 轨迹支持非均匀缩放父节点，位置与宽度仍使用世界单位；父变换不可逆时不提交几何。
- 截面按记录顺序连接，不生成轨迹细分、平滑曲面或圆角。大时间步不会补出运动过程中缺失的截面；急转和低帧率下需要业务提高采样频率或提供中间截面。
- 网格以整个对象参与透明排序，没有跨轨迹的逐三角形透明排序。单条轨迹内部自交仍可能出现透明叠加差异。

节点拥有自己的动态几何，销毁时释放它；共享材质、贴图和绑定端点由调用者管理。

## 动态特效材质

```haxe
import hx.material.AnimatedEffectMaterial3D;

var material = new AnimatedEffectMaterial3D(baseTexture, BlendMode3D.ADD, 0x66bbff);
material.maskTexture = maskTexture;
material.noiseTexture = noiseTexture;
material.uvSpeedU = 0.2;
material.uvSpeedV = -0.1;
material.uvScaleU = 2;
material.distortion = 0.05;
material.dissolve = 0.3;
material.edgeColor = 0xffcc66;
material.edgeWidth = 0.08;
material.edgeIntensity = 1;

// 显式推进材质时间，也提交本帧修改过的参数；共享材质每帧只更新一次。
material.update(dt);
```

参数含义：

| 参数 | 含义 |
| --- | --- |
| `uvSpeedU/V` | 每秒 UV 位移，可为负 |
| `uvScaleU/V`、`uvOffsetU/V` | 主贴图缩放和固定偏移 |
| `repeatUV` | 默认在主贴图区域内重复；关闭后越界坐标夹取到边缘 |
| `maskTexture` | 用原始、未滚动的 UV 采样，红通道乘 alpha 作为透明遮罩；为空视为全白 |
| `noiseTexture` | 取未预乘的红通道；为空使用程序化连续噪声 |
| `noiseScale` | 噪声坐标倍率，必须大于零 |
| `noiseSpeedU/V` | 噪声移动速度 |
| `distortion` | 两个噪声采样形成 UV 偏移，幅度以贴图区域为单位 |
| `dissolve` | 零完全显示，一完全隐藏，中间按噪声阈值裁剪 |
| `edgeWidth`、`edgeColor`、`edgeIntensity` | 溶解边缘范围、颜色和叠加强度 |

`update(0)` 不推进时间，但会提交参数；暂停时可使用它。`resetTime()` 将时间归零并提交参数；也可传入非负起始时间。材质不自动订阅帧事件，`Effect3D` 也不代替业务推进共享材质。

基础 UV、遮罩和噪声都支持 `BitmapData.rect` 图集区域，后端会处理底层纹理填充并将采样限制到区域内的像素中心。重复使用 Shader 内部坐标环绕，不要求非二次幂贴图启用硬件 `REPEAT`。边缘过滤采用区域内夹取，贴图自身仍需适合重复；不保证跨边界无缝线性过滤。

动态材质对整个材质贴图区域做变换。如果主贴图包含序列帧，它不会识别和独立环绕每个动画格；需要滚动或扰动序列帧单格时，应将格子作为独立 `BitmapData.rect` 使用，或另写逐格 Shader。

动态材质固定保留遮罩和噪声两个辅助槽，即使某个纹理为空，也用后端白色纹理绑定。它至少需要三个可用纹理槽；启用阴影时还需保留阴影槽。超过能力时明确报错，基础材质继续使用原路径。

`fragmentDeclarations`、`fragmentUVCode`、`fragmentCode` 和 `uFx` 参数由本类维护，业务应通过公开字段修改效果；需要完全自定义 Shader 时直接使用 `Material3D` 或基础特效材质。

## 组合时间轴

```haxe
var effect = new hx.display3d.Effect3D();
scene.root.addChild(effect);
effect.addEmitter(smoke, 0);
effect.addRibbon(trail, 0, 1.2);
effect.addRibbon(ribbon, 0.2, 0.5);
effect.play();

// 更新运动、动画、挂点和相机之后调用，不再单独推进轨道节点。
effect.update(dt, scene.camera);
```

`addRibbon` 接受 `Ribbon3D` 及其子类 `Trail3D`。第三个参数是采样持续时间，必须为正有限秒数；采样结束后，历史轨迹继续老化，播放器等全部粒子和轨迹收尾才完成。

时间步跨过轨道截止点时，播放器分开推进采样段与收尾段，但端点位置来自业务当前帧，不会反向求取动画的中间姿态。暂停或 `speed = 0` 时不采样新轨迹；既有弹道轨迹仍根据当前相机重建。重播清空全部轨道；循环包含尾部寿命。

## 自定义采样扩展

`Material3D` 新增 `fragmentUVCode` 和辅助纹理绑定：

```haxe
material.setTextureUniform("uDetail", detailTexture);
material.fragmentUVCode = "localUV=fract(localUV+vec2(0.1,0.0));";
material.fragmentCode = "vec2 detailUV=uDetailRect.xy+clamp(localUV,0.0,1.0)*uDetailRect.zw;"
    + "color.a*=texture2D(uDetail,clamp(detailUV,uDetailClamp.xy,uDetailClamp.zw)).r;";
```

后端自动声明 `sampler2D uDetail`、`vec4 uDetailRect` 和 `vec4 uDetailClamp`，不需要在 `fragmentDeclarations` 中重复声明。区域参数分别为起点与大小、半像素内缩后的最小与最大 UV。`localUV` 只有在 `fragmentUVCode` 非空时才存在于片元主函数中。

`setTextureUniform(name, null)` 绑定白色；`removeTextureUniform(name)` 移除绑定及自动声明。调用者要同步移除依赖它的 Shader 代码。名称不能与内置或已有数值 uniform、区域参数冲突。

辅助纹理使用材质相同的过滤设置、固定 `CLAMP` 包裹方式。若主贴图和辅助贴图引用同一底层纹理，主贴图也必须为 `CLAMP`，避免同一纹理对象出现冲突采样状态。需要重复时优先使用 Shader 区域环绕。

带采样前处理或辅助纹理的材质按材质实例隔离批次；同一个实例仍可合批，不同实例即使参数相同也可能拆批。Shader 程序按代码及采样器名称复用。相同的数值 uniform 再次提交不会重复派发材质变更。

OpenFL 后端同步修改 `MeshBatch3D`、`MultiTextureShader3D`、`Program3DInfo`、`Renderer3D` 和 `ShadowPass3D`。辅助纹理与阴影纹理预留独立槽位，并沿用现有 GL 状态保护与采样状态恢复。带自定义 UV 代码的物体不走简化阴影投射路径，避免忽略 UV 裁剪而投出错误轮廓。

- 跟随火球的橙色弹道拖尾，采样结束后自然淡出。

- 暂停时保留镜头旋转；舞台销毁后释放输入、控制器、网格、材质和程序化贴图。

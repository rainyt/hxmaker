# 3D 导航使用说明

`hx.navigation3d` 将显式路点图、A* 搜索和角色路径跟随接在已有运动学角色控制器之上。世界位置均代表脚底；不注册全局更新器，不修改 Scene3D 输入、帧调度或多纹理合批。

## 图与搜索

```haxe
var graph = new hx.navigation3d.NavGraph3D();
var start = graph.addNode(new hx.geom.Vector3D(0, 0.002, 0), "入口");
var goal = graph.addNode(new hx.geom.Vector3D(0, 0.002, 4), "出口");
var doorEdges = graph.connectBoth(start, goal);
var path = graph.findPath(start, goal);
if (path.status == hx.navigation3d.NavPathStatus3D.FOUND) {
    trace(path.points);
}
// 关闭门时也应启用真实碰撞体，通路和碰撞须由业务同步修改。
for (edge in doorEdges) edge.enabled = false;
```

`connect` 创建有向边，`connectBoth` 返回两条边。重复连接返回原边，不覆盖其成本或开关。默认成本为三维距离，可指定非负有限成本，包括零。A* 使用二叉最小堆，启发式按所有有效边的最低成本距离比缩放，零成本连接可退化为 Dijkstra，仍保证最短路。

节点、边的启用状态、成本、位置或拓扑变更增加图的 `revision`。通过 `moveNode` 改位置，读取位置和路径返回副本。搜索结果携带成本、展开数、版本及包含起终点的路径快照。搜索预算默认展开 4096 个节点，耗尽返回 `SEARCH_LIMIT`，不应当作已证明不可达。

状态包括 `FOUND / INVALID_START / INVALID_GOAL / UNREACHABLE / SEARCH_LIMIT`。图持有节点和边，移除或清空会解除归属；编号不复用。调用方不能直接构造节点或边。

## 跟随与更新

```haxe
var agent = new hx.navigation3d.NavAgent3D(graph, controller);
agent.speed = 3;
agent.setDestination(goal, start);

// 业务每帧调用一次；不要再单独调用 controller.update。
var result = agent.update(dt);
// 用 result.displacement 决定 Idle/Walk，再各更新一次动画与相机。
model.update(dt);
cameraControl.update(dt);
```

代理借用图和控制器，不拥有模型或资源。控制器负责重力、胶囊扫掠、跨步、贴地及坡度限制。代理只产生水平速度并根据真实位置检查路点，按距离和 dt 限速避免越过目标。到达需同时满足水平半径和脚底高度容差，防止同 X/Z 的另一楼层误报到达。

未指定起点时，在最大接入距离内选取最近的安全节点。默认检查高度差与整段胶囊扫掠，避免隔墙接入；显式给起点也不能绕过检查。默认接入保守，不模拟楼梯跨步；复杂路线可提供无副作用的 `canAttach(position, node)`，项目须自行确认该连接确实可走。建议在楼梯、坡道入口与出口放置脚底路点，跨层连接沿可行走表面配置。

`pause/resume` 保留路线，暂停期间 update 仍推进重力；`stop` 清空路径、目标与失败原因。图变化会在下一次非零 update 重规划。`autoRepath=false` 时报告需要重规划，停止使用旧路径。已到达或失败状态不自动重新启动，项目可显式 `setDestination/repath`。

持续没有接近当前路点时，默认 1.5 秒进入 `BLOCKED`；初始重叠无法解开时立即阻挡。代理不对未知障碍每帧重搜，也不会自动产生绕行路线。项目更新通路后显式重新规划。`failureReason` 提供中文反馈；失败的目标保留用于 UI，只有 stop 或 dispose 清空。

## 适用边界

这是基础路点导航框架，连接由项目为具体角色尺寸和运动参数验收。它尚不包含自动 NavMesh 生成、任意三角形地面导航、动态局部避障、多角色拥挤处理、移动平台或跳跃连接。角色尺寸、跨步或坡度参数变化后，项目应同步更新可走边。

导航模块不读取 GPU 状态，不新增材质或逐角色 shader uniform。路径标记使用共享几何和材质，兼容网格继续按原规则多纹理合批。无界面浏览器使用软件 WebGL 的运行结果用于功能回归，不作为硬件性能基线。

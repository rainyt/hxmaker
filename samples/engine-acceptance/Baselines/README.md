# 基线记录

当前没有本示例的实测性能数据。代码与资源准备完成，不等于编译、画面、生命周期或性能验收通过。

用户运行示例后，可将导出的 JSON 复制到此目录，并为文件标记设备、构建版本与日期。每份基线应同时记录：

- hxmaker 与 hxmaker-openfl 的源码提交或本地修改标记；构建参数中的版本标签。
- 设备型号、系统、浏览器、窗口大小、缩放和设备像素比。
- 正常前台运行、关闭浏览器录制和额外渲染诊断的采样条件。
- 人工画面确认与尚未通过的项目。

优化前后使用相同资源、负载配置、实际离屏尺寸与阴影状态比较。至少重复运行，查看 P95 / P99、长帧与波动；不要仅凭平均 FPS 或单次最快结果下结论。

保留未完成和失败记录，但不得把它们当作通过基线，也不得沿用旧示例的数据填补本示例结果。
